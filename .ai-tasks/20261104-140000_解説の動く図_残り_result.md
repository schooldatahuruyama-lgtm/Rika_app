## 指示書と違えた点

1. **`focal-length` の屈折光の終点の式**: 指示書の `(280, 110 + 40 * 120 / f)` は、(160,70) から焦点 (160+f, 110) を通る直線にならない（f = 60 で y 190。正しくは 150 で、静止図も (280,150)）。指示書のテスト「屈折光の直線が (160 + f, 110) を通る」と合わないので、`(280, 70 + 40 * 120 / f)` にした（f = 60 で 150、f = 40 で 190）。
2. **文字の位置の移動**（指示書の「重なりがあれば label の座標を動かしてよい」による）:
   - `refract-in` の「法線に近づく」: (170,215) → **(20,215)**。どの角度でも屈折光の矢じりが文字の上に来たため、何もない水の左側に移した。
   - `total-reflection` の下の文字 2 つ: (10,215) → **(10,232)**。入射角 30° のとき光源（電球、y ≒ 195、光の線は半径 22 まで）が文字と重なったため。
   - `reflect-names` の「入射角」「反射角」: (100,95)・(172,95) → **(104,72)・(168,72)**。入射角が 25°〜36° のとき光線が文字を横切ったため、光線の始まりより上に移した（「法線」の文字はそのまま (166,54)）。
   - `image-size-by-distance` の「物体」: object の label にすると、物体が焦点に近いとき（d_o = 60）「物体」と焦点の「F」がくっつくため、object の label をやめ、別の label **(ox − 16, 162)**（1 段下）に書いた。
3. `total-reflection` の lamp は、どちらの場合も反射光・屈折光のあとに置いた（電球が光線の始まりの上に描かれるように）。指示書には順の指定がない。
4. `grow` は、長さの計算の誤差で長さ 0 の辺ができないよう、残りが 1e-9 以下になったら止める。
5. テストの追加分: 指示書の項目に加えて、`stage`・`u`・`deg` などの道具と、`image-size-by-distance` で 3 本の光線が像の先・焦点・中心を通ることも確かめた。
