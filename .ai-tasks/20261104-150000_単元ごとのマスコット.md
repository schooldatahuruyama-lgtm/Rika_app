# 実装指示書: 単元ごとに変わるマスコット（先生キャラクター）

作成・実装: Claude Code（Fable）2026-11-04。小さな変更のため Claude Code 本体が実装し、Codex がレビューする。

## 目的

ユーザーの要望: マスコットの名前は「キューブ先生」にし、**単元が変わったら先生も変わる**ようにする。
ユーザーが Google ドライブに用意した 6 体（A〜F。同梱の `unit_mascots.json` に単元→先生の対応がある）を `assets/mascots/` に置いてあるので、教材データの単元に `mascot: 'E'` のように担当を書き、画面はそれを見て先生を出す。

## 仕様

- `forUnit(unit)`: `unit.mascot` が `MASCOTS` のキーならその先生、それ以外（未指定・不明・unit が null）は `MASCOTS[FALLBACK]`（まる先生。同梱 JSON の fallback に合わせる）。
- `svg(size, mascot)`: `mascot` 省略時は fallback。`<img class="mascot" src=画像 width height alt=名前>`。
- 復習セッション（`session.kind === 'review'`）は `conceptId` から、ステージのセッションは `stageId` から単元を引く。
- 画面側のヘルパー `sessionMascot(ctx, session)` を 1 つ作り、提案・結果・祝いで共用する。

## テスト

- `forUnit({ mascot: 'E' })` が キューブ先生 / `mascot_E.svg`、`forUnit({})`・`forUnit(null)`・`forUnit({ mascot: 'Z' })` が まる先生。6 体の画像ファイルが存在する。
- `svg(80, forUnit({ mascot: 'B' }))` に `mascot_B.svg` と `alt="しずく博士"`。`celebrateMarkup` も mascot を受け取る。
- 登録簿: `unitOfStage('s-a1').id === 'u'`、`unitOfConcept('c-a').id === 'u'`、知らない id は null。
- 教材: `light.unit.mascot` が `MASCOTS` のキー。

完了の条件: `npm test` がすべて成功。ブラウザでホームにキューブ先生が出て、名前が「キューブ先生」になっている。
