## (1) アクセントカラー

- 選べる色（id と表示名、`--blue` / `--blue-dark` / `--blue-soft` / `--bg` / `--line` の値）:

| id | 名前 | --blue | --blue-dark | --blue-soft | --bg | --line |
|---|---|---|---|---|---|---|
| `blue`（既定） | あお | #1A5CFF | #0F44CC | #DCE6FF | #EEF3FF | #C9D5F0 |
| `teal` | みずいろ | #0E9AA7 | #0A7682 | #D6F1F4 | #EAF7F8 | #BFE3E7 |
| `green` | みどり | #178A4C | #10673A | #D8F0E1 | #ECF7F0 | #BFE0CB |
| `purple` | むらさき | #7A4FD6 | #5C36AE | #E6DDFA | #F3EFFC | #D4C8F0 |
| `pink` | ピンク | #E0508A | #B83A6E | #FBDCE8 | #FDF0F5 | #F0C4D6 |

- `--shadow` は色ごとに `rgba(<--blue-dark の RGB>, 0.12)`。`--ok`・`--warn`・`--star` は変えない（正解・おしい・星の意味を保つ）。
- 適用: `document.documentElement.dataset.theme = id`（`blue` のときは属性を外す）。`<meta name="theme-color">` の `content` も `--blue` の値に書きかえる。CSS は `:root[data-theme="teal"] { --blue: ...; ... }` のように 4 色分。
- 設定画面: カード「見た目と読みやすさ」に「アクセントカラー」の見出しと、5 つの丸いボタン（`button.color-swatch`、背景がその色、`aria-label` に名前、選択中は `aria-pressed="true"` と白い内側の輪）。押すとすぐ反映して保存（`ctx.setPrefs({ theme })`）。プロフィールがないときは既定の色で、カードに「プロフィールを選ぶと色を変えられます」と出す。

## (2) ふりがな（ルビ）

- 設定: `profile.ruby` は `'off'`（既定）か `'on'`。設定画面の同じカードに「ふりがな」の見出しと 2 つのボタン（「なし」「つける」、選択中は `aria-pressed`）。押すとすぐ反映して保存。
- しくみ（`js/ruby.js`）:
  - `WORDS`（`content/readings.js`）は `{ '振動': 'しんどう', '動か': 'うごか', ... }` の形。キーは漢字を 1 字以上ふくむ語（送りがなの**語幹**まで。例: `動か`→`うごか` で「動かす・動かして・動かそう」に当たる。`大き`→`おお`、`大切`→`たいせつ`、`見え`→`み`、`見る`は `見`→`み` ）。値はひらがな（カタカナ語の読みも可）。
  - `annotate(text, words)` → `[{ text, reading }]`（`reading` は null か読み）。**最長一致**で左から走査し、辞書の語に当たればその部分に読みを付け、当たらなければ 1 文字進める。辞書の語は長い順に試す（起動時にキーを長さ順に並べた配列を作っておく。`Map` でもよい）。漢字をふくまない部分は読みを付けない。
  - `apply(rootNode, words)`: `rootNode` 以下のテキストノードを走査し、`annotate` で読みが付く部分を `<ruby>語<rt>よみ</rt></ruby>` に置きかえる（`document.createElement`。innerHTML は使わない）。飛ばすもの: `ruby`/`rt` の中、`script`/`style`/`svg`（SVG の text には ruby を入れられない）/`input`/`textarea`/`select`/`option`/`button` の中の `rt`、`[data-no-ruby]` の中。置きかえた `ruby` 要素には `class="rq-ruby"` を付ける。
  - `strip(rootNode)`: `ruby.rq-ruby` を元のテキストノードに戻す（設定を「なし」にしたとき）。
  - `setEnabled(flag)`: `true` なら `document.body` に `apply` し、`MutationObserver`（`childList: true, subtree: true, characterData: true`）で以後の変化にも `apply` する（追加されたノードだけに `apply`。自分が入れた `ruby` による変化は無視する: `characterData` の対象が `rt` の中か、追加ノードが `.rq-ruby` ならスキップ）。`false` なら observer を止めて `strip(document.body)`。
  - Node でも読み込めるように（`annotate` と辞書の整形はブラウザに依存しない。`apply`/`setEnabled` は `document` があるときだけ定義）。公開: `RikaQuest.ruby = { annotate, apply, strip, setEnabled, prepare }`（`prepare(words)` が長さ順の配列を作る）。
- 見た目（CSS）: `ruby.rq-ruby { ruby-position: over; } rt { font-size: 0.5em; color: var(--muted); }`。行の高さは `line-height` 1.6 のままで、`rt` が重ならないか 375px 幅で確かめる。ボタンの中の文字にもふりがなが付いてよい（高さは 56px 以上を保つ。`.btn { line-height: 1.3 }` など必要なら調整）。
- 辞書 `content/readings.js` の作り方: `content/*.js`（`curriculum.js` と `readings.js` 自身は除く）と `js/ui-screens.js`・`js/ui-problems.js`・`js/app.js`・`index.html` の中の日本語の文字列から、漢字をふくむ語をすべて拾い、読みを付ける。**中学生が読めない可能性のある語だけ**ではなく、**すべての漢字の語**に付ける（設定が「つける」のときは全部にふりがなが付く仕様。先生の希望は「漢字のルビふり」）。目安 1,500〜3,000 語。語の切り方の決まり:
  - 複合語はまとめて 1 語にする（例: `初期微動継続時間`→`しょきびどうけいぞくじかん`、`質量パーセント濃度`→`しつりょうぱーせんとのうど`）。ただし長い語の中の短い語（`質量`、`濃度`）も別に登録する（別の文脈で単独で出るため）。
  - 送りがなのある語は語幹で登録（`燃や`→`も`、`伝わ`→`つた`、`集め`→`あつ`、`選ぼ`→`えら` など、文に出る形をすべて拾う）。
  - 同じ漢字で読みが変わる語は、送りがなで区別できる形で登録する（`重な`→`かさ`、`重い`→`おも`、`重さ`→`おも`、`生物`→`せいぶつ`、`生ま`→`う`、`生え`→`は`）。区別できない語（`一日` など）は数が少ないので、文脈で多いほうにする。
  - 数字と単位の `g`・`cm`・`℃` には付けない。カタカナだけの語には付けない。
- `tools/ruby-missing.js`: 上の対象ファイルの日本語の文字列を集め、`annotate` にかけて読みが付かなかった**漢字の連続**（前後の送りがなつき）を回数順に表示する。`node tools/ruby-missing.js` で実行。辞書を作ったあとで、これが 0 件（または固有名詞だけ）になるまで辞書を増やす。

## js/app.js の変更

- `normalizeStore`: `p.theme` が上の 5 つの id でなければ消す。`p.ruby` が `'on'`/`'off'` でなければ消す。
- `makeCtx()` に `get prefs() { return { theme: profile.theme || 'blue', ruby: profile.ruby || 'off' } }`（profile がなければ既定）と `setPrefs(patch)`（profile がなければ false。値を検査して profile に入れ、`applyPrefs()` を呼び、`save()` の結果を返す。保存に失敗したら元に戻す）。
- `applyPrefs()`: 今の profile の `theme` を `document.documentElement.dataset.theme` と `meta[name=theme-color]` に反映し、`RQ.ruby.setEnabled(ruby === 'on')` を呼ぶ。`go()` の最初（プロフィールの切りかえで変わるため）と `start()` で呼ぶ。`RQ.ruby` がない（読み込み失敗）なら黙って飛ばす。
- 冒頭の ctx の説明コメントにも足す。

## テスト（tests/ruby.test.js）

- `annotate('光の振動数', { 振動数: 'しんどうすう', 振動: 'しんどう' })` → `[{ text: '光', reading: null }, ... ]` で最長一致（`振動数` が 1 語）。
- 語幹: `annotate('音を伝わらせる', { 伝わ: 'つた' })` → `伝わ` に読み、`らせる` は null。
- 辞書にない漢字は null のまま。漢字のない文は 1 要素で null。空文字は `[]`。
- `content/readings.js`: すべてのキーに漢字（`\p{Script=Han}`）をふくみ、値はひらがな・カタカナ・ー だけ。重複なし。
- 網羅率: `content/*.js`（curriculum・readings を除く）の `unit` の全テキスト（lessons の text、問題の prompt・explanation・hint・options の text・fill の text・blanks の options/answer、ステージ・領域・概念の title、unit.title）と、`js/ui-screens.js`・`js/ui-problems.js`・`js/app.js` の文字列リテラル（`'...'` の中の日本語）について、`annotate` で読みが付いた漢字の文字数 ÷ 漢字の総文字数 ≥ 0.98。足りないときはメッセージに足りない語の上位 30 件を出す。
- `apply` は DOM が必要なので自動テストはしない。ブラウザで、ふりがなを「つける」にしてホーム・単元一覧・解説カード・問題（選択肢・穴うめ）・結果画面・設定を見て、`rt` が重ならず、ボタンが押せることを確かめる（幅 375px）。
