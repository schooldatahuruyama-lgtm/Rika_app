## 判断したこと

- weather-dr5-p2 は、元は「前線が通過した時間帯」を選ぶ問題。数値の内容を 1 問入れるため、同じ表から「通過のあいだに下がった気温」を答える number に変えた（時間帯を見つけないと答えられない）。前線の種類を読む問題は r1 に残っている。
- electricity-dr5・dr6、weather-dr6 は、テーマに計算や表の数値の内容がほぼないので number は入れていない（指示書の「数値の内容があれば」に従った）。
- 新しい図はすべて既存の部品（eveningSky・PLANET_TABLE・tape/dots・電圧計は rect と circle）で描いた。図の中の文字は答えにならない（ラベルはア・イ・ウ・エだけ。端子の値・空の方角の意味は prompt に書いた）。region の中心どうしは 44px 以上はなれている。
