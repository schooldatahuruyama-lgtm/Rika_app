## ミニプリントの使い方

- プリントの**出題のねらい（何を問うか）・用語・数値の例・よくある誤答**を参考にする。文そのものは写さず、このアプリの口調（やさしい・短い・生徒を責めない）で書き直す。
- プリントにある図は「どんな場面を描くか」の参考にし、図は `figures.js` の部品で描き直す。
- ドライブの図版フォルダに出版社の図（学図など）があっても、それは**転載しない**。

## 単元ファイルの形（`content/<id>.js`）

- `content/light.js` と同じ IIFE。Node では `module.exports = { unit }`、ブラウザでは `root.RikaQuest.content.register(unit)`。
- `unit = { id, title, mascot, concepts, areas }`。`id` は `content/curriculum.js` の表の id とファイル名に一致。`title` と `mascot` も表と一致させる。
- **大きさの目安（1 単元）**: 領域 2〜3 つ × 各 2 ステージ（合計 4〜6 ステージ）、概念 4〜6 つ。各ステージ 4〜5 分（`minutes`）。
- ステージ: `{ id, areaId, title, minutes, concepts: [概念 id], lessons: [2〜4 枚], warmup: choice 1 問, problems: [4〜6 問], retryPool: [類題] }`。
  - `id` は `<領域>-<番号>`（例 `sound-1`）。問題 id はステージ id に `-w1`（warmup）、`-p1..`（問題）、`-t1..`（用語問題）、`-r1..`（類題）を付ける。確認問題は `<概念>-k1..`。カードは `<ステージ>-c1..`。
  - レッスンカード: `{ id, text（40〜160 字。大切な言葉は **語句**）, figure（必ず付ける） }`。`anim` は付けない（動く図は光専用）。
  - `problems` には **用語問題（`term: true` の fill）を 1 問**と、**図・操作型（figure-choice か drag）を 1 問以上**入れる。
  - 各概念について、全ステージの `retryPool` に合計 2 問以上の類題（同じ概念）。
- 概念: `{ id, title, basic（この概念の前に戻る基礎の概念 id か null）, lessonStageId（その概念を解説するステージ）, checkPool: [3 問以上] }`。
- 問題の共通項目: `id, concept, prompt, explanation（正解の理由を 2〜3 文。生徒を責めない）, hint（1 文）`。
- 形式: `choice`（選択肢 3〜4、正解は a〜d）、`fill`（`text` に `[b1]`、`word` は語群 3 つ程度から選ぶ、`number` は `tolerance` と `unit`）、`figure-choice`（図の `region` から選ぶ。`region` の `r` は 22 以上、`label` はア・イ・ウ）、`drag`（`draggable.itemId` の部品を `axis: 'x'|'y'|'xy'` に動かす、`target`、`samples: { correct, wrong }`。許容は `config.tolerance.dragPx` = 16px なので、`samples.wrong` は 40px 以上はなす）。
- 数値: 中学理科で習う単位と有効数字にする（例: 速さ m/s、密度 g/cm³、電流 A、電圧 V、抵抗 Ω、質量 g、温度 ℃）。計算問題は `fill` の `number` を使い、`tolerance` を適切に（例: 割り切れない商は 0.1）。

## 守ること

- 教科書名・出版社名（東京書籍・啓林館・大日本図書・教育出版・学校図書・学図・東書・啓林）を書かない。文章・図はすべて自作。実在の生徒名は書かない。
- 赤い大きな ×、減点など、失敗を強調する表現を使わない。`explanation` は「ここを見直そう」と次の一歩を示す。
- 用語は中学校の教科書で使う標準の言い方（例: 「振動数」「密度」「質量保存の法則」）。ひらがな・漢字は中学生向け。
- 図は 320×240 の中に収め、文字は 12px 以上、タップ対象（`region`・ドラッグ）は直径 44px 以上。
- 1 問 1 概念。`prompt` に図の説明（ア・イ・ウ の意味）を入れて、図だけに頼らない。
- `js/`、`css/`、`content/light.js`、`content/curriculum.js` は変えない。足してよいのは `content/<id>.js`、`index.html` の `<script>`（`content/light.js` の後ろに学年・表の順）、`sw.js` の `PRECACHE`（同じ順）と `VERSION`、`docs/reports/content/<id>.md`、テスト（`tests/content-<id>.test.js` は作らない。`tests/content-all.test.js` が全単元を検査する）。
- `git add`・`git commit` はしない。ネットワークからパッケージを追加しない。サブエージェントを起動しない。
