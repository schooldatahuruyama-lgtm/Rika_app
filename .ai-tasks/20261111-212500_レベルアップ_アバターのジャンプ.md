# 実装指示書: レベルアップの祝いに、生徒が選んだアバターのジャンプの画像を出す

作成: Claude Code（Fable）2026-11-11。実装: Opus。レビュー: Codex。
ユーザー指示: 「レベルアップ時の画像を、ユーザーが選択したアバターが飛び跳ねているような画像にしたい。それぞれのアバター画像をもとに、飛び跳ねている画像を ChatGPT の Image に作らせて差し替える」。
要件定義書・設計書の該当: レベルアップの祝い演出（結果画面）。いまは単元の担当の先生（マスコット）が出ている。

## 決めたこと

1. ジャンプの画像は `assets/avatars/jump/<名前>.png`（poyon / mojari / nyokki / purumo / mukuri / nemune。320×320、背景は透明の PNG）。**画像は controller が ChatGPT で作って置く**。いまは同じ名前の仮の画像（ふつうのアバターの写し）が置いてある。実装は画像の中身に頼らない。
2. レベルアップの祝い（`js/ui-screens.js` の `levelup-overlay`）は、先生のマスコットの代わりに、**いまの生徒のアバターのジャンプの画像**を出す。吹き出しの文（「レベル N になった！」）と「タップでとじる」は今のまま。
3. 生徒のアバターが分からないとき（プロフィールが取れない）は、今までどおり先生のマスコット（`RQ.mascot.celebrateMarkup`）を出す。`avatarOf` は知らない id を先頭のアバターにするので、プロフィールがあれば必ずアバターが決まる。
4. ジャンプの画像が読みこめなかったとき（`error` イベント）は、1 回だけ、ふつうのアバターの画像（`a.image`）に差しかえる（無限にくり返さない）。
5. 祝いを出しておく時間 `LEVELUP_MS` は 1500 → 2000（ジャンプが 3 回ほど見える）。タップ・キーで消えるのは今のまま。
6. 動き: 画像そのものがジャンプの絵なので、CSS では上下に大きめにはねさせる（下で少しつぶれる）。`prefers-reduced-motion: reduce` では動かさない。
