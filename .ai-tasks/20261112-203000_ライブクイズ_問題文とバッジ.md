# 実装指示書: ライブクイズ — 答え合わせに問題文を出す／上位 5 人にバッジ

作成: Claude Code（Fable）2026-11-12。実装: Opus。レビュー: Codex。設計: 設計書 14 章（ライブクイズ）と 4.5.1（バッジ）への追加。
ユーザー指示: 「ライブクイズで答えを出すときに、問題文も生徒の画面に出るように」「ライブクイズが終わったら 1 位から 5 位の生徒にはバッジが送られるように、バッジも新たに作って」。

## 決めたこと

1. **答え合わせの画面（生徒）に問題文を出す**: `js/ui-live.js` の `revealCard` で、「N 問目の答え合わせ」の下に `kindMark(q)` と `el('p', { class: 'live-question', text: plain(q.prompt) })` を出す（出題中の画面と同じ見た目）。
2. **順位の記録**: 部屋が `ended` になったとき、生徒の端末は自分の最終順位を 1 回だけ学習記録に入れる。記録の形: `rec.liveResults = [{ at（ISO）, code, rank, players（参加者数）, score }]`（部屋コードごとに 1 つ。同じ code が来ても足さない）。入れる経路は、問題の回答と同じ `ctx.live.record(events, profileId)`。出来事の形: `{ kind: 'liveResult', code, rank, players, score }`。処理済みの管理は回答と同じ仕組み（`doneQids`・`applyDone`）で、問題 id の代わりに `L().RANK_QID`（`'_rank'`）を使う（切れて戻っても、読み込み直しても二重に入らない。保存に失敗したら次の受信で取り直す）。
3. **バッジ 3 つ**（`js/badges.js` の DEFS の末尾に足す。順位は参加者が **2 人以上**の部屋だけ数える）:
   - `live-top5`: title 'ライブ トップ 5'、glyph '5位'、color 'green'、description 'ライブクイズで 5 位以内に入ろう。'、test: `s.bestLiveRank >= 1 && s.bestLiveRank <= 5`
   - `live-top3`: title 'ライブ トップ 3'、glyph '3位'、color 'orange'、description 'ライブクイズで 3 位以内に入ろう。'、test: `… <= 3`
   - `live-first`: title 'ライブ 1 位'、glyph '1位'、color 'orange'、description 'ライブクイズで 1 位になろう。'、test: `s.bestLiveRank === 1`
   - `stats` に `bestLiveRank`（`liveResults` のうち players ≥ 2 の rank の最小。無ければ 0）と `liveResults`（件数）を足す。
   - 1 位の生徒は 3 つとも取る（取った順に見せる）。
4. **取ったバッジを最終順位の画面に出す**: `ctx.live.record` の戻り値に `newBadges`（この呼び出しで新しく付いたバッジ id の配列。無ければ `[]`）を足す（`js/app.js` の `liveRecord`: `awardBadges` の前後の `rec.badges` のキーの差）。生徒の画面は、順位を記録したときの `newBadges` を `j.newBadges` に持ち、`endedCard` の順位表の下に「新しいバッジ！」の card（`ui-screens.js` の結果画面と同じ見た目: `H.badgeMedal(def, true, 64)`＋title＋description。`badge-new-list` / `badge-item` の class）を出し、`ctx.markBadgesSeen(ids)` で見たことにする（結果画面と同じ）。効果音 `RQ.sfx.play('badge')` を 1 回（結果画面と同じ守り）。
5. 画像 `assets/images/badges/live-first.png` / `live-top3.png` / `live-top5.png`（160×160）は controller が ChatGPT で作って置く。いまは仮の画像（perfect.png の写し）が置いてある。`sw.js` の PRECACHE のバッジの並びに 3 行足す（VERSION は変えない）。
