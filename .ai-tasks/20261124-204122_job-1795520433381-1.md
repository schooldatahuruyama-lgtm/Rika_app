# 実装指示書: レベル・連続学習・バッジを 1 枚のカードにまとめる

## 1. 目的

- 依頼: ホームと記録画面で別々のカードになっている「レベルと経験値」「連続学習」「バッジ」を、1 枚にまとめて見やすくする。
- 関係する項目: 設計書 `docs/superpowers/specs/2026-11-03-rika-quest-design.md` の 4.1（画面一覧のホームと記録）、4.5（経験値・レベル・連続学習）、4.5.1（バッジ）。要件定義書 `docs/requirements.md` の「ゲーミフィケーションの拡張」。
- 変えるのは見た目と画面の組み立てだけ。計算（`js/xp.js`）、判定（`js/badges.js`）、保存の形は変えない。

## 2. 先に決めたこと（利用者から見える動き）

| 決めたこと | 内容 | 理由 |
|---|---|---|
| まとめる範囲 | ホームと記録画面の両方 | 部品を両方の画面で共用している。片方だけ変えると見た目がそろわない |
| カードの題 | 両方の画面で「いまのがんばり」 | 「レベルと経験値」「経験値とレベル」のゆれをなくす。漢字がないので、ふりがなの辞書に影響しない |
| カードの形 | いちばん上に 3 つの数字（レベル・連続学習・バッジ）を横に並べ、その下に細かい内容を線で区切って置く | 3 つの数字がひと目で分かる |
| 記録画面のバッジ一覧 | 23 個の一覧（`badgeListCard`）は、今のまま別のカードで残す。まとめたカードのすぐ下に置く | 長いので、1 枚に入れると見にくい |
| 記録画面の「最近のバッジ」 | 出さない（すぐ下に全部の一覧があるため）。「バッジを見る」ボタンも出さない | 同じ内容が 2 回並ぶのをさける |
| 連続学習の文字 | 「n 日 連続」をやめ、ラベル「連続学習」と値「n 日」にする | 3 つの数字の形をそろえる |
| 消える表示 | なし。今ある情報（Lv、合計 / 次 XP、バー、あと n XP、連続日数、ひとこと、曜日の丸、バッジの数、最近の 3 つ、ボタン）はすべて残す | 位置と並びだけを変える |

## 3. 変えるファイルと内容

### 3.1 `js/ui-screens.js`

`levelCard`・`streakCard`・`badgeHomeCard` の 3 つをなくし、次の関数に置きかえる。置く場所は今の `levelCard`・`streakCard` のあたり（`questCard` の後）。`badgeMedal`・`badgeDate`・`earnedBadges`・`badgeCountText`・`badgeListCard`・`weekDates` は変えない。

#### `statusCard(ctx, rec, now, today, home)`

- 引数: `ctx`（画面の ctx）、`rec`（今の記録）、`now`（`ctx.now()` の Date）、`today`（`RQ.xp.localDate(now)`）、`home`（true ならホーム用。「最近のバッジ」の節を出す）。
- 戻り値: `card([...], 'status-card')` の要素。
- 中身（上から順）:
  1. `cardTitle('いまのがんばり')`
  2. `ul.status-summary`。`li.status-tile` を 3 つ。各 li は `span.status-label`（ラベル）と `span.status-value`（値）の 2 つ。
     - `li.status-tile.status-tile-level`: ラベル「レベル」、値 `'Lv ' + level`
     - `li.status-tile.status-tile-streak`: ラベル「連続学習」、値 `count + ' 日'`
     - `li.status-tile.status-tile-badge`: ラベル「バッジ」、値 `badgeCountText(rec)`（例: `4 / 23 個`）
     - 値は今と同じく 1 つの文字列を 1 つの要素に入れる（数字と単位を別の要素に分けない。分けるとふりがなの読みが変わるおそれがある）。
  3. `levelSection(ctx, rec)`
  4. `streakSection(rec, now, today)`
  5. `home` が true のときだけ `badgeRecentSection(ctx, rec)`

#### `levelSection(ctx, rec)`

- 戻り値: `div.status-section`。
- 中身: `h3.status-heading`「次のレベルまで」、経験値のバー、`div.status-xp-row`（`span`: `total + ' / ' + next + ' XP'`、`span.muted`: `'あと ' + Math.max(0, next - total) + ' XP で Lv ' + (level + 1)`）。
- バーと割合の計算は今の `levelCard` のものをそのまま移す（`lower`・`span`・`ratio`・`percent`、`role="progressbar"`、`aria-label="次のレベルまで"`、`aria-valuemin`・`aria-valuemax`・`aria-valuenow`、`bar.firstChild.style.width`）。式は変えない。

#### `streakSection(rec, now, today)`

- 戻り値: `div.status-section`。
- 中身: `h3.status-heading`「今週の学習」、`p.muted`（ひとこと）、`ol.week-dots`。
- ひとことの文と、曜日の丸の組み立て（`aria-label`、`is-done`・`is-today`、`aria-hidden`、`data-no-ruby`、warmup を除く数え方）は今の `streakCard` のものをそのまま移す。

#### `badgeRecentSection(ctx, rec)`

- 戻り値: `div.status-section`。
- 中身: `h3.status-heading`「最近のバッジ」、最近取った 3 つの `ul.badge-recent`（1 つもなければ今と同じ `p.muted`「ステージをクリアしたり、続けて学習したりすると取れるよ」）、`button('バッジを見る', () => ctx.go('record'), 'btn-block')`。
- `ul.badge-recent` の li の作り方（`li.badge-item` に `badgeMedal(x.def, true)` と `span.badge-title`）は今の `badgeHomeCard` のまま。

#### 連続日数の求め方

- 「続いているか」と「日数」（今の `streakCard` の `alive` と `count`）は、タイルとひとことの両方で使う。小さな関数 `streakNow(rec, today)`（戻り値 `{ alive, count }`）にまとめ、両方から呼ぶ。式は今のまま（最後の学習日が今日かきのうのときだけ数え、それ以外は 0）。

#### 呼び出し元

- `renderHome`: `levelCard`・`streakCard`・`badgeHomeCard` の 3 行を `section.append(statusCard(ctx, rec, now, today, true));` の 1 行にする。
- `renderRecord`: `levelCard`・`streakCard` の 2 行を `section.append(statusCard(ctx, rec, now, today, false));` の 1 行にする。次の行の `badgeListCard(rec)` は残す。
- `renderRecord` の上のコメント（「経験値とレベル、連続学習、バッジ」のところ）を、新しい並びに合わせて直す。

## 4. 追加するテスト

`tests/link.test.js` の、`classApp(t, { unitScreens: true })` を使っているテストの近くに、次のテストを 1 つ足す。書き方（1 行に複数の assert を並べる形）は周りに合わせる。

- 名前の例: `home: レベル・連続学習・バッジは「いまのがんばり」の 1 枚にまとまる`
- 手順: `classApp(t, { unitScreens: true })` で開き、`await f.ready; await f.settle();` のあと、`f.ids['screen-home']` を見る。
- 確かめること
  - `textContent` に「いまのがんばり」「次のレベルまで」「今週の学習」「最近のバッジ」「バッジを見る」が入っている。
  - `textContent` に「レベルと経験値」が入っていない。
  - `textContent` に `Lv 1`、`0 日`、`'0 / ' + require('../js/badges.js').DEFS.length + ' 個'` が入っている（新しい記録のとき。記録が新しくない場合は、その記録の値に合わせる）。
  - `f.nodes(f.ids['screen-home'])` のうち `attrs.role === 'progressbar'` のものが、ちょうど 1 つ。
  - `className` に `status-tile` を含む要素が、ちょうど 3 つ。
- テスト用の DOM は小さい（`createElement`・`append`・`setAttribute`・`firstChild`・`style`・`textContent` くらいしかない）。新しい関数では、今の `levelCard`・`streakCard`・`badgeHomeCard` が使っている操作（`el`・`append`・`firstChild.style.width`）だけを使う。`querySelector`・`classList`・`insertAdjacent...` などを使わない。
- 数が合わないなど、テスト用の DOM の都合で確かめられない項目があったら、条件をゆるめずに、理由を報告に書く。

記録画面は、このテストの道具では描かれない。記録画面はブラウザで確かめる（6 章）。

## 6. 端の場合

### 不正な入力

- この変更で、利用者が入力するところは増えない。出す値はすべて記録（`rec`）から読む。
- `rec.streak` がない・`lastDate` がない: 今と同じく「0 日」と「今日から始めよう！」を出す。
- `rec.level`・`rec.xp` の型のちがい・負の数・とても大きい値: 今の `levelCard` と同じ式で、そのまま出す（割合は 0〜100 に丸める今の式を保つ）。この変更で新しい検査は足さない。
- バッジの取った日時が読めない記録: 今と同じく `earnedBadges` が後ろに並べる。変えない。
- レベルが `config.levels` の上限を超えたとき: `RQ.xp.nextLevelXp` が `levelStep` で続きを返すので、今と同じ式でバーと「あと n XP」を出す。

### 重複と境界

- バッジ 0 個: タイルは `0 / 23 個`。「最近のバッジ」の節は、案内の文とボタンだけ。
- バッジ 1〜2 個: 取った分だけを左から並べる（3 列の枠のうち、空いた列はそのまま空ける）。
- バッジ 23 個すべて: タイルは `23 / 23 個`。最近の 3 つだけを出す。
- 連続 0 日: タイルは `0 日`。最後の学習日がおとといより前のときも `0 日`。
- 経験値がちょうどレベルの境目: バーは 0%、「あと n XP」は次のレベルまでの全部。今の式のまま。
- 大きい値（`Lv 100`、`365 日` など）とせまい画面（幅 320〜375px）: タイルの中で折り返してよい。カードの外に はみ出さない・横にスクロールしない。バッジの名前が長いときも、列の中で折り返す。
- 記録画面では、バッジの数がまとめたカードのタイルと、下の一覧のカードの 2 か所に出る。これはそのままでよい（一覧のカードは変えない）。

### 失敗の見せ方

- バッジの絵が読めないとき: 今と同じく、文字入りの SVG メダルに替わる。
- この変更で新しく起きる失敗はない。新しい注意の文や帯は足さない。
- 規則に合わない値を黙って別の値に直すことはしない（上の「不正な入力」のとおり、今の出し方を保つ）。
