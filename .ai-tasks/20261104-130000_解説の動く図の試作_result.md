## 指示書と違えた点・判断した点

1. **解説画面から別の画面へ移るときの後片付けを足した**（`renderLesson` が `() => section.replaceChildren()` を返す）。app は画面を移るとき前の section を `hidden` にするだけで中身を残すため、解説 → 問題と進むと動く図の要素が `isConnected` のまま残り、隠れた画面でループが動き続けるため。次に別の画面を描くときに app が呼ぶ後片付け（既存の仕組み）を使った。
2. **モーダルの body を空にする場所を 2 つにした**。「閉じる」ボタンは `<form method="dialog">` で閉じ、Esc でも閉じるので、`closeLessonDialog` を通らない。`openLessonDialog` で `dialog.onclose = () => body.replaceChildren()` を付け、`showModal` がない環境用に `closeLessonDialog` でも空にした。
3. `anim.js` に `prefersReducedMotion()` を足して公開し、`lessonCardBody`（`lessonFigure`）から使った。指示書の「matchMedia がなくても落ちない」をここにまとめるため。
4. `figures.js` の `COLOR` には濃い灰色がなかったので、`COLOR.shadow = '#4A4A4A'` を足した。
5. テスト「両方の ray の端点の y は 180 未満」は、当たる点 (160, 180) の端は 180 ちょうどなので、当たる点でない端（入射光の始点・反射光の終点）が 180 未満であることを確かめる形にした。当たる点が (160, 180) であることは別に確かめている。
6. `frame` の t に数でないものが来たときは 0 として扱う。
