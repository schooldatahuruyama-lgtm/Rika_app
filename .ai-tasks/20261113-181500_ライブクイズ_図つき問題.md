# ライブクイズ: 図（SVG）つきの問題を出せるようにする

## 目的

要件定義書 `docs/requirements.md` のライブクイズ（先生の出題にクラス全員がリアルタイムで答える）の拡張。
いまは教材の問題のうち、図のない選択式と、図のない空欄 1 つの穴埋めだけを取りこんでいる（`live.questionFromProblem`）。
図のある問題（選択式 58 問、穴埋め 54 問、図から選ぶ 416 問）が出せないので、図（`js/figures.js` の scene）を問題に持たせて、生徒の画面と先生の画面に描くようにする。

- 図のある選択式（`type: 'choice'` で `figure` あり）: 図を出して、今までどおりの選択式
- 図のある穴埋め（`type: 'fill'`、空欄 1 つ、`figure` あり）: 図を出して、自由記述（text）
- 図から選ぶ（`type: 'figure-choice'`）: 図の中の「選ぶ場所」（region）をタップして答える選択式
- `ray-draw`・`drag` は今までどおり出さない

図のデータ（scene）は部屋のデータ（Firebase）の `questions/<id>/figure` に入れる。生徒の端末にない教材（先生が AI で作った教材）の図も出せるようにするため。Firebase の規則（`docs/live/firebase-rules.json`）は `questions` の形を検証していないので変えない。

## 変更するファイル

### `js/live.js`

1. 定数を足す。
   - `MAX_FIGURE_JSON = 20000`（図 1 つの JSON 文字数の上限。教材でいちばん大きい図は約 8,700 字）
   - `MAX_FIGURE_ITEMS = 200`
   - `MAX_REGIONS = 8`（図から選ぶの「選ぶ場所」の数。教材では最大 8）
   - `api` に `MAX_FIGURE_JSON`, `MAX_REGIONS` を出す。

2. `safeFigure(raw)` を足して `api` に出す。
   - 戻り値: `{ width, height, items }` か `null`。
   - `raw` がオブジェクトでなければ `null`。`width`・`height` は `isNum` で 1〜2000 のときその値、それ以外は 320・240。
   - `items` は `valuesOf(raw.items)` を使う（Firebase は配列をキー 0,1,2… のオブジェクトで返すことがある）。オブジェクトで `type` が空でない文字列のものだけ残し、`MAX_FIGURE_ITEMS` を超えたら `null`。各 item は浅いコピー。`points` があれば `valuesOf(points).map(p => valuesOf(p))` で「配列の配列」に戻す（`[[x, y], …]` の形。`js/figures.js` の `pointsOf` がこの形を期待する）。
   - `JSON.stringify` した長さが `MAX_FIGURE_JSON` を超えたら `null`。
   - item の中身の値（座標・文字・画像の src）はここでは検査しない。`js/figures.js` が `num`・`escapeText`・`imageSrc` で安全に描く。

3. `regionOptions(figure)` を足す（内部用でよいが、`api` にも出す）。
   - `safeFigure` 済みの図から `type === 'region'` で `id` が空でない文字列の item を集め、`{ id, text }` の配列にする。`text` は `label` → `name` → `id` の順で最初にある文字列。
   - 2 個未満、`MAX_REGIONS` を超える、id が重なる、のどれかなら `null`。

4. `isFigurePick(question)` を足して `api` に出す。
   - `kindOf(question) === 'choice'` で `question.figure` があり、`question.options` の id がすべて図の region の id にふくまれるとき `true`。これが「図の中をタップして答える問題」の判定（UI がこれで描き方を変える）。

5. `questionFromProblem(problem, where)` を変える。
   - `problem.figure` があれば `safeFigure` を通し、`null`（大きすぎるなど）なら問題ごと `null` を返す。有効なら戻り値に `figure` を入れる。**図のない問題の戻り値には `figure` キーを入れない**（今のテストの `deepEqual` と同じ形を保つ）。
   - `fill`: 図のあるものも `textFromFill` で取りこむ（今の「図のある穴埋めは `null`」をやめる）。`figure` は上のとおり付ける。
   - `figure-choice`: `regionOptions(figure)` を選択肢にし、`answer` は `problem.answer`（region の id）。選択肢に `answer` がなければ `null`。`kind: 'choice'`。問題文の長さの検査は choice と同じ（`MAX_PROMPT`）。
   - `ray-draw`・`drag`・その他は `null` のまま。
   - コメント（148 行目あたり）を「図は scene のまま持つ」に直す。

6. `safeQuestion(q, key)`: どの kind でも `q.figure` を `safeFigure` に通し、有効なら戻り値に `figure` を入れる（無効・無しならキーを入れない）。
   - 注意: `cleanOptions` は選択肢の数に上限がない（`MAX_OPTIONS` は自作の問題だけ）。図から選ぶの 8 個もそのまま通る。

7. `customQuestion` は変えない（自作の問題に図はない）。

### `js/ui-live.js`（生徒）

1. `LABELS` を `['ア','イ','ウ','エ','オ','カ','キ','ク']` にする（`OPT_CLASSES` は 4 色のまま `i % 4` で回る）。
2. `figures()` アクセサ（`RQ.figures`）と `figureBox(scene, opts, cls)` を足す（`js/ui-problems.js` の `figureBox` と同じ: `div.figure-box` に `figures().sceneSvg(scene, opts)` を `innerHTML` で入れる。`innerHTML` に入れてよいのはこの SVG 文字列だけ）。
3. `showCard`: `kindMark`・問題文の**あと、答える部分の前**に、`q.figure` があれば図を出す。
   - 図の中をタップして答える問題（`L().isFigurePick(q)`）では、`answerPart` で次のようにする。
     - `figure-box is-tappable` の図を出し、`sceneSvg(q.figure, { highlightRegion: 選んでいる id })`。region の `g[data-item-type="region"]` に `role="button"`・`tabindex`（答え済み・時間切れは `-1`、それ以外 `0`）・`aria-label`（選択肢の text）・`aria-pressed` を付け、クリックと Enter/Space で選ぶ（`js/ui-problems.js` の `renderFigureChoice` の `draw`/`pick` と同じ作り）。
     - 選ぶと下書き（`draftOf(j, q)` に `region` を足す）に入れて `repaint()`。答え済みなら `mine` を強調して押せない。
     - 「決定」ボタン（`btn-primary btn-block live-decide`、選んでいないか時間切れなら `disabled`）で `answer(j, q, dr.region)`。
     - 選択肢のボタン（`live-options`）は出さない（ア〜クは図の中に描かれている）。
     - hint: 「図の中の場所をタップして「決定」」。
   - それ以外の kind（図つきの choice・text）: 図を `figureBox(q.figure)` で問題文のあとに出し、答える部分は今までどおり。
4. `revealCard`: 問題文のあとに `q.figure` があれば図を出す。図の中をタップする問題は `highlightRegion: q.answer`（正解の場所を濃くする）。
5. `rightText(q)`: `isFigurePick(q)` のときはラベル（`labelOf(q, q.answer)`）だけ返す（「ア ア」と二重にならないように）。`answerText` はそのままでよい（ラベルを出す）。
6. `KIND_MARKS` に図タップ用の印は足さず、hint だけで案内する。

### `js/ui-live-host.js`（先生）

1. `LABELS` を 8 つにする（生徒と同じ）。
2. `figures()`・`figureBox` を足す（生徒と同じ）。
3. `showCard`: 問題文のあとに `q.figure` があれば図を出す。`isFigurePick(q)` のときは `optionsBox` を出さない（ラベルは図の中にある）。
4. `revealCard`: 問題文のあとに図を出す（図タップの問題は `highlightRegion: q.answer`）。横棒は今までどおり選択肢ごと（図タップの問題は text がラベルなので、`live-bar-label` の中の 2 つ目の span（`plain(o.text)`）は `isFigurePick(q)` のとき出さない）。
5. `rightText(q)`: 生徒と同じく図タップの問題はラベルだけ。
6. `pickCard` の説明文を「ステージを選ぶと、その選択式の問題（図から選ぶ問題もふくむ）と、空欄が 1 つの穴埋めの問題（記述）が入ります（線を引く問題・動かす問題と、長い問題は入りません）。」にする。ステージの行の「（選択式 N 問・記述 M 問）」はそのまま。
7. `selectedCard` の問題の行に、`q.figure` があれば `KIND_TAGS` と同じ見た目（`span.live-kind`）で「図」を足す。

### `tests/live.test.js`

- 「questionFromProblem: 選択式、図は落とす、長い問題文は除く」を直す: 図のある choice は `figure` を持つ（`safeFigure` の形）。`figure-choice` は region が選択肢になる。図のない choice の戻り値に `figure` キーがないことはそのまま。
- 「図のある穴埋め…取りこまない」のテストを「図のある穴埋めは text として取りこみ、`figure` を持つ」に直す（`force-3-p1`・`electricity-mp3-p2` を使う）。
- 足すテスト:
  - `safeFigure`: オブジェクト以外 → null。`items` がキー `0,1,…` のオブジェクトでも配列に戻る。`points` が `{0:{0:1,1:2}}` の形でも `[[1,2]]` に戻る。`type` のない item は落ちる。items が 201 個 → null。JSON が `MAX_FIGURE_JSON` を超える → null。width/height の既定値。
  - `regionOptions`: label → name → id の順。2 個未満・9 個以上・id 重なりで null。
  - `isFigurePick`: 選択肢が region と一致すれば true。図のない choice・text は false。
  - `questionFromProblem`: 教材の `figure-choice`（例: `content/light.js` の `straight-1-p3`。region の `name` が「ア」〜「ウ」）が `kind: 'choice'`、options が `[{id:'r1',text:'ア'},…]`、answer `'r2'`、`figure` あり。`ray-draw`・`drag` は null のまま。
  - `safeQuestion`: `figure` が有効なら残る、壊れていればキーごと落ちる。
  - `newRoom` → `safeRoom` を通しても `figure` が残る（往復）。
- 教材全体を回す確認（既存の「教材の問題を id で探す」の書き方で）: 全ステージの `figure-choice` のうち `questionFromProblem` が null になるものは、問題文が `MAX_PROMPT` を超えるものだけであること（region が 9 個以上の問題はないはず。あれば数を assert に書く）。

## 守ること

- 既存のコードの書き方（IIFE、`root.RikaQuest.<name>`、日本語コメント、`el()` での DOM 作り）に合わせる。
- `innerHTML` を使うのは `figures().sceneSvg` の戻り値だけ。利用者の文字は `textContent`（`el` の `text`）で入れる。
- `docs/live/firebase-rules.json` は変えない。
- `js/figures.js`・`js/ui-problems.js`・`content/*` は変えない。
- `js/live.js` から `js/figures.js` を require しない（Node のテストで図の描画に依存しないため）。
- ネットワークからパッケージを足さない。git の状態を変える操作（commit・add）はしない。
