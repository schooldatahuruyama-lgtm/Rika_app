## 指示書と違えた点・懸念

- docs のドリルの節は表でなく「カード: c1 …／c2 …」の行にカードが書いてあるので、そのカードの文の後ろに「（動く図: io-daniell）」を足した。
- docs 冒頭の既存の領域の行（「領域 3 つ: … miniprint …」など）と、ion.js・electricity.js の先頭コメントの「領域 3 ミニプリント」は古いままにした（指示は 1 行足すだけのため。足した行に組みかえ後の領域を書いた）。
- ch-precipitate-mass（chemical-change-dr6-c2）は、はじめ静止図の文字の検査に落ちて外したが、controller がテストを直して付け直した（docs の chemical-change.md にも「（動く図: ch-precipitate-mass）」を足した）。追加の依頼で全カードを見直したが、文字の検査だけが理由で外したカードはほかになかった（ほかは内容の食い違い・表・まとめ・合う kind なしが理由）ので、追加はなし。
- ファイルの改行は元のまま（ion.js・electricity.js は CRLF、chemical-change.js は LF）。
