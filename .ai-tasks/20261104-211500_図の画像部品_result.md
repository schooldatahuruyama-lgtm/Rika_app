## 指示書と違えた点・判断した点

- 下地の縦の位置は指示書に式がなかったので、文字の高さを「ベースラインから size × 0.85 上〜0.15 下」と見て、上下 2px の余白で `y = ベースライン − size × 0.85 − 2`、`height = size + 4` とした。
- `fill` は指示書の書き方どおり `white`（色コードでなく名前）にした。
- `opacity` は数でない値・範囲外も 0〜1 にそろえる（`clamp01`）。`null`・未指定・空文字のときは属性を書かない。
- 正規表現 `IMAGE_SRC_RE` は `js/figures.js` からは公開せず、`tests/content-all.test.js` に同じものを書いた（教材の検査を描画側と独立させるため）。
