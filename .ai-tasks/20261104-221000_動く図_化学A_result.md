## 計画と違えた点

1. **su-water-displacement**: 試験管の中の水は `rect` ではなく `polygon` で描いた（rect だと丸い底の外へ水の角がはみ出すため。底の丸みに沿わせた）。「気体が水をおし出す」は (220,96) だと右はしからはみ出し、水そうのふちとも重なるので、2 行に分けて試験管の左 (110,62)・(110,78) に置いた。気体がたまり終わった後（t ≥ 0.85）は泡を止めた。
2. **st-particles**: 気体の粒の向き（増える側・減る側）も粒ごとに変えた（px は `(x0−227)/132` か `1 − (x0−227)/132`）。
3. **st-heating-curve**: 伸びる線は `growLine` ではなく `partial`（静止図の青い線に矢印がないので矢印を付けない）＋先の丸。小さなビーカーの氷は、水があるときは水面に浮くようにした。
4. **sl-dissolve**: 左のビーカーの水面は y 123 なので、右の粒の並び（y 116 など）をそのまま −160 すると水の外に出る。縦のずれを水の深さの比（77/93.5）で縮めた。テストは「横の位置は右 − 160、粒は水面より下」にした。粒の出発点は solution.js の `DOTS.lump` の並び。
5. **sl-recrystallize**: 動いている間も「X g が」「結晶になる」の 2 行を静止図と同じ位置に出し、X だけを変えた（20 ℃ で「78 g が」になり静止図と一致するので、文字の例外は不要）。曲線の上の丸は orange（r 5）。
6. **ch-water-formation**: 「原子の組み合わせが変わる」は blue にした。
7. **io-dissociation**: 「結晶」は (160,108) だと水面の線と重なるので (160,112)。0.6 以降のゆれは `1.5·(osc(t) − osc(0.6))` の形にして、restT 0.6 で静止図とぴったり同じ位置にした。
8. **io-daniell**: 電子の位相を 1/8 ずらした（t = 0 で道すじのはしにいると、1 周の終わりと始めがつながらないため）。Zn2+・Cu2+ は「1 周に 2 回の行き来」を、Zn2+: 静止図の位置 → 水溶液の奥へ遠ざかって小さくなる → 亜鉛板の表面で大きくなって出てくる → 静止図の位置、Cu2+: 静止図の位置 → 銅板の表面へ動いて小さくなって消える → 水溶液から近づいてくる → 静止図の位置、にして t = 0 で静止図の位置・1 周でつながるようにした。銅の層は銅板の brown と同じ色では見えないので、brown と ink を 35% 混ぜた色。モーターの回る線は半分の長さ 8。
9. **io-migration**: H+ の色は計画の `red` ではなく、ion.js の ION_FILL と同じ `pink`（赤い部分の上でも見え、「粒子・イオンの色は静止図と同じ」の決まりにも合う）。赤い部分が H+ の直径より細い動き始めは、H+ を糸の左（x 155）にそろえる。
10. **io-neutralize**: 動いている間、H+ は半径 19 → 10、OH- は 19 → 16 に小さくして、水分子の丸の大きさにつなげた。

## 理科として自信のない点

- **io-daniell** の Zn2+ が「水溶液の奥へ遠ざかって小さくなる」動きは、1 周をつなぐためのモデルの見せ方で、実際にイオンが小さくなるわけではない。Cu2+ が銅板で「消える」のは銅原子になって板に付くことの表現（銅の層が少しずつ厚くなる）。
- **ch-open-container** の 80.0 → 79.6 g は計画どおり説明のための例の値（静止図には数字がない。はかりの rect の label に足した）。
- **ch-open-container** の左（ふたあり）の泡は、容器の中で上下するだけにした。実際には発生した気体は容器の上の空間にたまる。
- **st-heating-curve** のビーカーの「液体と気体」の区間で、水面の下から泡が上がる絵（沸とう）。0℃の区間の「固体と液体」は氷が小さくなり水が増える絵。
- **st-particles** の液体の粒は、静止図の位置のまわりを ±7px ほど動くだけで、粒どうしが入れかわるほどは動かない（計画の式どおり）。
