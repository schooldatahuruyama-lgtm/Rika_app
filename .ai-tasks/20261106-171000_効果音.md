# 実装指示書: 効果音（正解・不正解・レベルアップ・新しいバッジ）

作成: Claude Code（Fable）2026-11-06。実装: Opus。レビュー: Codex（上限中は Claude）。ユーザー指示: 「問題の正解、不正解時とレベルアップ時の効果音をつけてください」。

## 方針（決めたこと）

- 音声ファイルは置かず、**Web Audio API で合成**する（オフラインで動く、ライセンス不要、容量ゼロ）。
- 生徒ごとに設定でオン・オフ（`profile.sound`。既定は **オン**）。設定画面の「見た目」の近くに「効果音」の切りかえ。端末のミュートには従う。
- 音は短く、やさしい音色（教室で鳴っても耳ざわりでない）。
  - 正解: 2 音の上がるチャイム（例: C5 → E5、各 0.09 秒、サイン波、小さめ）
  - 不正解: 低い 2 音の下がる音（例: A3 → F3、各 0.12 秒、三角波、さらに小さめ。「ブー」ではなく「ぽん、ぽん」程度）
  - レベルアップ: 上がるアルペジオ 4 音＋最後を少しのばす（C5 E5 G5 C6、計 0.6 秒）
  - 新しいバッジ: レベルアップと同じ音（結果画面で両方あるときは 1 回だけ）
- iOS/Android の制限: `AudioContext` はユーザー操作の中で作る・`resume()` する。最初の操作（答えるボタン）の中で作ればよい。作れない環境では何もしない（例外を出さない）。
