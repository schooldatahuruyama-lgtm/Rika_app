## 指示書とちがう点・判断したこと

1. **自由記述の入力中に描き直されたときの対策を足した**（指示書にない）。ほかの生徒が答えるたびに受信で描き直すので、(a) 描き直しの前に入力欄にフォーカスがあれば、描き直したあともフォーカスとカーソルの位置を戻す、(b) 日本語の変換（IME）の途中（compositionstart〜compositionend）は描き直しを待ち、変換が終わったら描き直す（変換が切れるのを防ぐため）。
2. **並びかえでタップした選択肢にも `is-picked` と `aria-pressed="true"` を付けた**（番号に加えて、押したものが濃いまま見えるように）。
3. **先生の並びかえの答え合わせでは、答えの一覧の上に選択肢（ア〜エ）も出す**（「ウ → ア → イ」のラベルが何を指すかわかるように）。答えが 1 件もなければ「だれも答えていません。」と出す（text も同じ）。
4. **複数回答・並びかえの「決定」の行は、答えたあとは出さない**（選択肢は disabled のまま、「答えた！」を出す）。
5. **`optionsBox` の第 2 引数（`correctOnly`）を外した**（どこからも true で呼ばれておらず、`q.answer` との直接比較が残るため）。
6. 自作の text の正解・別解の入力欄にも `maxlength` = `MAX_TEXT_ANSWER` を付けた。
7. 指示書の表にない class `live-decide`（「決定」の行の上の余白）を CSS に足した。

## 確かめたこと（headless Edge。偽の live-db をメモリで差しかえ）

確かめ用のページと CDP で動かすスクリプトはスクラッチパッド（`…\scratchpad\d_check`）。先生と生徒の画面を同じページに描き、43 項目すべて OK。

- 問題を選ぶ: 「ルーペ・スケッチ・双眼実体顕微鏡（選択式 6 問・記述 1 問）」、案内文
- 自分で書く: 形ごとの案内文（multi・text・order）、形を変えたあとの select、4 つの形を足して一覧の印（複数回答・記述・並びかえ・無印）
- multi: 決定（0 こ）は押せない、押すたびに選ぶ／外す、決定（2 こ）で `'a,c'` を送る、決定後は disabled と「答えた！」、先生の横棒の緑 2 本と「正解: ア・ウ（正解 1 / 1 人）」、生徒の ○・正解・あなた
- text: 入力欄の属性、空なら送らない、変換中は描き直しを待つ、描き直しで書きかけとフォーカスが残る、「反射。」を送る、送ったあと disabled、先生の一覧（「反射。 — 1 人」が緑、「くっせつ — 1 人」）と「正解: 反射（別解: はんしゃ）（正解 1 / 2 人）」、生徒の ○
- order: タップで番号 1・押せなくなる、全部タップするまで決定は押せない、時間切れでは押せない、やり直すで番号が消える、正しい順で送る（`'b,c,a'`）、先生の「正解: イ → ウ → ア」と一覧の緑、生徒の ○ とあなた
- choice: 印も決定もなし、× と「正解: ア 速い」（あなた は出さない）、最終順位
- 画面の写し（幅 1400 の中に 420px の枠）で、印・番号の丸・入力欄の行・答えの一覧の見た目を確かめた
