## 指示書と違えた点・気づいた点

1. **先生の画面の自作の問題の入力**: `LABELS` を 8 つにすると、`customCard` の選択肢の入力・複数回答のチェック・正解の select が 8 つになってしまう（`LABELS.map` を使っているため）。`LABELS.slice(0, L().MAX_OPTIONS)` にして 4 つのままにした（指示書にはないが、`js/ui-live-host.js` の中の変更）。
2. **CSS のセレクタ**: 指示書の例は `.screen-live` だが、セクションには `screen-live` のクラスがなく id だけなので `#screen-live`・`#screen-live-host` にした。また、幅 480px 未満の画面で既存の `.card .figure-box`（左右の負の余白で図をカードいっぱいに広げる）が打ち消されないよう、`@media (min-width: 480px)` の中に入れた。
3. **図の箱のクラス**: `figureBox` は `figure-box live-figure` に（`.live-figure` で上下の余白）。生徒の図タップの箱には目印として `live-figure-pick` も付けた。
4. **キーボードのフォーカスを戻す**: 生徒の画面はほかの生徒が答えるたびに描き直すため、region にフォーカスがあると外れてしまう。`paint()` で、描き直す前に region（`.live-figure-pick` の中）にフォーカスがあれば、描き直したあと同じ region にフォーカスを戻すようにした（自由記述の入力欄のカーソルを戻す処理と同じ考え方）。
5. 答えたあと・時間切れの region に `aria-disabled="true"` も付けた。
6. `isFigurePick(null)` が例外にならないよう、先に `isObject(question)` を確かめている（`kindOf(null)` は 'choice' を返すため）。
7. `regionOptions` の text は「label → name → id のうち最初の空でない文字列」とした（空文字の label は飛ばす）。
8. 図タップの問題で、生徒が答えたあとの「あなた: …」の行は、今までの choice と同じく出さない（正解の場所の強調と「○ 正解！」で分かるため）。
