# 実装指示書: 解説カードの「動く図」の試作（2 枚）

作成: Claude Code（Fable）2026-11-04。実装: サブエージェント（Opus）。レビューは Codex。

## 目的

ユーザー（理科教員）の要望: 解説の図を、ただの図解でなく動きのあるものにしたい。GIF や動画生成 AI ではなく、アプリの中で SVG を動かす方式で、まず **2 枚だけ試作**して見てもらう（設計書 4.1「各カードは短い文と図（SVG）」の図を、動く図に置き換える試み）。

試作する 2 枚:
1. `straight-1-c3`（物体を光源に近づけると影が大きくなる）: 物体が光源に近づいたり離れたりし、スクリーンの影がそれに合わせて大きく・小さくなる。
2. `reflect-1-c3`（反射の法則）: 入射角が 20°〜50° の間でゆっくり変わり、反射光がそれに合わせて動く。入射角と反射角の数値が常に同じ値で表示される。

動きは **数式で計算した正確な位置**で描く（光線が物体のはしを通る、入射角＝反射角）。見た目は既存の静止図（`js/figures.js` の item）と同じ部品を使う。

## 1. `js/figures.js`: item `shadow`

`{ type: 'shadow', x, y1, y2 }`: スクリーン上にできる影。`x` の位置に `y1`〜`y2` の縦線を描く。`stroke` は濃い灰色（既存の `COLOR` に合う色。なければ `#4A4A4A`）、`stroke-width` 12、`opacity` 0.55、`stroke-linecap` `butt`。`ITEM_TYPES` に入る（`DRAW` に足すだけで入るはず）。`centerOf` など type で分岐している箇所があれば、`x` と `(y1+y2)/2` を中心として扱う。

## 2. `js/anim.js`

IIFE 形式（他の `js/*.js` と同じ。Node では `module.exports`、ブラウザでは `root.RikaQuest.anim`）。`figures` は Node では `require('./figures.js')`、ブラウザでは `root.RikaQuest.figures`（既存モジュールの取り方に合わせる）。

```
KINDS = ['shadow-size', 'reflect-law']
PERIOD_MS = 4000                       // 1 周の時間
frame(kind, t) → scene                 // t は 0 以上 1 未満（1 周の中の位置）。{ width: 320, height: 240, items: [...] }。純粋関数
create(kind) → { element, start(), stop(), isPlaying() }   // ブラウザだけ。element は div.anim-box
```

`frame` の計算（座標は x 右向き、y 下向き、場面 320×240。角度は度。`c = Math.cos(2 * Math.PI * t)`）:

### `shadow-size`（straight-1-c3）

- 光源 `lamp` は (40, 120)。スクリーン `screen` は x = 280、y1 = 30、y2 = 220。
- 物体 `object` は `x = ox`, `y = 143`, `height = 45`, `label = '物体'`（先端 y = 98、根元 y = 143。静止図と同じ）。`ox = 150 - 50 * c`（t = 0 で 100 = 光源に近い、t = 0.5 で 200 = 遠い）。
- 光源から物体の先端・根元を通ってスクリーンへ届く 2 本の `ray`（`arrow: true`）: 始点 (40, 120)、終点 (280, yTop) と (280, yBot)。
  `yTop = 120 - 22 * 240 / (ox - 40)`、`yBot = 120 + 23 * 240 / (ox - 40)`（直線 光源→先端 (ox, 98) を x = 280 まで延ばした式。ox = 100 で yTop = 32, yBot = 212。ox = 200 で 87, 154.5）。念のため 30〜220 に収める。
- 影 `shadow`: `x = 280, y1 = yTop, y2 = yBot`。
- 文字 `label`: (104, 232) に、`ox < 150` なら `'光源に近い → 影は大きい'`、それ以外は `'光源から遠い → 影は小さい'`。
- items の順: ray 2 本 → object → screen → shadow（スクリーンの上に重ねる）→ lamp → label。

### `reflect-law`（reflect-1-c3）

- 鏡 `mirror`: (30, 180)–(290, 180)。当たった点 H = (160, 180)。法線 `normal`: `{ x: 160, y: 120, angle: 0 }`（静止図と同じ）。
- 入射角 `theta = 20 + 30 * (0.5 - 0.5 * c)`（20°〜50°〜20°）。`L = 110`、`s = sin(theta)`, `co = cos(theta)`（ラジアンに直して計算）。
- 入射光 `ray`（`arrow: true`）: (160 − L·s, 180 − L·co) → (160, 180)。反射光 `ray`（`arrow: true`）: (160, 180) → (160 + L·s, 180 − L·co)。
- 文字 `label`: (20, 40) に `'入射角 ' + d + '°'`、(200, 40) に `'反射角 ' + d + '°'`（`d = Math.round(theta)`。表示だけ丸め、座標は丸めない）。(120, 215) に `'入射角 ＝ 反射角'`。
- items の順: mirror → normal → ray 2 本 → label 3 つ。

### `create(kind)`

- `element = div.anim-box` の中に `div.figure-box`（`innerHTML = figures.sceneSvg(frame(kind, t))`。既存の `svgBox` と同じく、自分で作った SVG 文字列を入れるだけなので innerHTML でよい）と、その下にボタン `button.btn.btn-quiet.anim-toggle`（文字は再生中 `'とめる'`、停止中 `'動かす'`。`type="button"`、高さ 44px 以上）。
- `start()`: `requestAnimationFrame` のループ。`t = ((now - t0) % PERIOD_MS) / PERIOD_MS` で毎フレーム `figure-box` の innerHTML を描き直す（`t0` は再開時に、止めたときの t から続くように補正する）。**`element.isConnected` が false になったら自分でループを止める**（画面が切り替わって要素が外れたあとに動き続けない）。
- `stop()`: ループを止め、ボタンの文字を `'動かす'` に。
- 最初に描くのは t = 0 の絵（影は大きい、入射角 20°）。`window.matchMedia('(prefers-reduced-motion: reduce)').matches` のときは自動では動かさず（ボタンで動かせる）、それ以外は `lessonCardBody` が `start()` を呼ぶ。`matchMedia` がなくても落ちない。

## 3. `js/ui-screens.js`

`lessonCardBody(card)`: `card.anim` が文字列で、`RQ.anim` があり `RQ.anim.KINDS.includes(card.anim)` なら、`RQ.anim.create(card.anim)` の `element` を図の代わりに入れ、reduced-motion でなければ `start()` を呼ぶ。それ以外は今までどおり `card.figure` の静止図。解説画面と「解説を見る」モーダルの両方がこの関数を使う（モーダルを閉じると要素が外れてループが止まる。閉じても残る場合は `closeLessonDialog` 相当の場所で body を空にする）。

## 6. テスト

- `tests/anim.test.js`（新規）:
  - `KINDS` が 2 つ。`frame` は t = 0, 0.25, 0.5, 0.75 で `width 320, height 240` の scene を返し、item の type はすべて `figures.ITEM_TYPES` にあり、`figures.sceneSvg(scene)` が文字列を返す。知らない kind は例外を投げる。
  - `shadow-size`: t = 0 で物体 x = 100、影の長さ（y2 − y1）= 180。t = 0.5 で x = 200、長さ = 67.5。各 t で、2 本の ray の直線が物体の先端 (ox, 98) と根元 (ox, 143) を通る（外積が 1e-6 以下）。影は 30〜220 の中。文字は ox < 150 のとき「近い」、それ以外「遠い」。
  - `reflect-law`: t = 0, 0.1, 0.25, 0.5 で、入射光と法線のなす角と反射光と法線のなす角が等しい（`Math.atan2` で計算、差 1e-9 以下）。t = 0 で 20°、t = 0.5 で 50°。両方の ray の端点の y は 180 未満（鏡の裏へ行かない）。入射光の終点と反射光の始点が (160, 180)。2 つの角度の文字が同じ整数。
- `tests/figures.test.js`: `shadow` が `ITEM_TYPES` にあり、描くと `<line` を含む。`ITEM_TYPES` の数を固定しているテストがあれば 1 つ増やす。
- `tests/content-light.test.js`: `anim` を持つカードは `anim` が `KINDS` にあり、`figure` も持つ。`straight-1-c3` と `reflect-1-c3` がその 2 枚。
- `tests/offline.test.js` は `index.html` と `sw.js` を照合する。
