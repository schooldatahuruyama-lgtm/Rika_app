# 実装指示書: 写真ふうの画像を生物 5 単元の解説カードに組みこむ（優先度 A）

作成: Claude Code（Fable）2026-11-04。実装: Opus（単元ごとに分担）。レビュー: Codex（上限中は Claude）。計画: `docs/image-plan.md`（A の 48 枚）。

## 目的

先生の指示「動物や植物などの解説は、図より写真。生成した図版の上に説明の文字を置く形に」。ChatGPT で生成した画像（708×531 PNG。セッションの一時フォルダ `C:\Users\yan12\AppData\Local\Temp\claude\C--Users-yan12-Documents-keita-AI--------\06597260-147f-4081-8b2f-691841b121f6\scratchpad\gen_images\<単元id>\<カードid>.png`、記録 `.../gen_images/log.md`）を、`assets/images/<単元id>/<カードid>.png` に入れ、解説カードの `figure` を「`image` 部品＋文字・引き出し線」に差しかえる。

## 手順（単元ごと）

1. `docs/image-plan.md` の自分の単元の表（カード id、画像の内容、重ねる文字・矢印・region の案）と、`docs/figures-guide.md` の `image`・`text`（`bg: true`）・`line`・`arrow` の決まりを読む。
2. 画像は controller が 640×480 の JPEG（品質 82）に変換して `assets/images/<単元id>/<カードid>.jpg` に置く（PNG のまま入れない。**ファイル名は小文字**）。`src` は `.jpg`。
3. 各画像を Read ツールで**見て**、写っているものの位置（320×240 の座標に換算: 画像は 708×531 なので ×320/708）を確かめてから、`figure` を書き直す:
   ```js
   figure: scene([
     { type: 'image', src: 'assets/images/plants/plants-1-c1.png' },
     { type: 'line', points: [[x1, y1], [x2, y2]], color: 'ink', width: 2 },        // 引き出し線
     { type: 'text', x, y, text: 'おしべ', size: 14, bg: true, anchor: 'middle' },     // 白い下地つきの文字
   ]),
   ```
   - 文字は `bg: true` で白い下地を付け、写真の上でも読めるようにする。文字の大きさは 13〜16。文字どうし・文字と重要な部分が重ならないようにする。引き出し線は対象の近くまで（写真の上に線を引いてよい）。
   - 計画に `region`（ア・イ・ウ）の案があるカードは解説なので region は使わない（問題は今回の対象外）。
   - 写真で分かりにくい場合（生成が計画とずれている、細部が見えない）は、`log.md` の備考と自分の目で判断し、**その画像は使わず簡略図のまま残して**報告に書く。
   - `anim` のあるカードは `anim` を外さない限り画像にしない（計画 9 章のとおり、写真にするカードには anim を付けていない）。
4. `sw.js` は**触らない**（controller が後で `assets/images/` の一覧から `PRECACHE` を足す）。そのため `tests/content-all.test.js` の「PRECACHE にない」だけは失敗してよい（それ以外の検査は成功させる）。
5. `npm test` を全件成功させる（content-all の検査: src の実在・PRECACHE・形式。`tests/content-all.test.js` は触らない）。
6. 確認: Node で `figures.sceneSvg(card.figure)` を SVG に書き出し、`<image href>` を画像の絶対パスに置きかえた HTML を headless Edge で画像にして、文字の位置を目で確かめる（一時フォルダ `.../scratchpad/img_check_<単元id>/`）。内蔵ブラウザのタブは使わない。
7. `docs/reports/content/<単元id>.md` のカードの行に「（写真）」と書き足す。
8. 報告 `.ai-tasks/20261104-224000_画像の組みこみA_<単元id>_result.md`（状態、使った画像の数、使わなかった画像とその理由、テスト件数）。返事は 150 字程度。

## 守ること

- 変えてよいのは `content/<自分の単元>.js`、`assets/images/<自分の単元>/`、`docs/reports/content/<自分の単元>.md`。`sw.js` は触らない。ほかは触らない（`js/*`、`index.html`、テスト、ほかの単元）。
