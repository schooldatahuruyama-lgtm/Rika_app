## やること（前回の `.ai-tasks/20261104-224000_画像の組みこみA.md` と同じ手順）

1. 計画の表のカード・問題ごとに、**画像を Read で見て**、`photo('<id>')`（320×240 いっぱいに敷く `image` 部品）の上に `tag`（白い下地の文字、13px 以上）・`pointer`（引き出し線）・`region`（問題）を、写真の中の実際の位置に合わせて置く。文字は写真の大事な部分にかぶせない。余白がない写真（log の備考にあるもの）は、文字を写真の上下のふちに寄せるか、下地つきで置く。右はしの文字は `anchor: 'end'`。
2. 使い回し（既存の画像）は、その画像を Read で見て同じように文字を置く。ほかの単元の画像を使うときは `src` を直接書く（`image` 部品の `src: 'assets/images/<単元>/<id>.jpg'`）。
3. `content/basics.js` に `photo()`・`pointer()`・`tag()` の小道具を `content/plants.js` から写す（保存先 `assets/images/basics/`）。
4. 問題の図を写真にするもの（34 問）: figure-choice は region を写真の位置に、drag は対象と target を写真に合わせる。問題文の位置や色の説明は写真に合わせて直す（計画の「region の置き方」）。
5. **動く図（anim）が付いたカードには写真を使わない**（content-all の決まり: 写真のカードに anim を付けない）。計画で写真と動く図の両方になっているカードがあれば写真を優先し、anim を外す。
6. `sw.js` の `PRECACHE` に新しい画像 25 枚を足す（既存の画像と同じ並び方。VERSION は変えない）。
7. `docs/reports/content/<単元>.md` の該当カードに「（写真）」を付ける。
8. headless Edge で、写真を組みこんだカードを 5 枚以上（単元をまたいで）目で確かめる（内蔵ブラウザは使わない）。`npm test` 全件成功（`tests/content-all.test.js` の image の検査: src が実在し PRECACHE にあること）。
