## 構成（領域 2 × ステージ 2、概念 5）

| 領域 | ステージ | 内容 | 概念 |
|---|---|---|---|
| `state` 状態変化と粒子 (order 1) | `state-1` 固体・液体・気体 | 温度によって固体⇄液体⇄気体と変わる（状態変化）。物質そのものは変わらない。体積は変わるが質量は変わらない。ふつう固体＜液体＜気体の体積（水は例外: 氷は水より体積が大きい）。粒子のモデル: 固体は規則正しく並ぶ、液体は動く、気体は飛び回る。 | `change`（状態変化と質量・体積、basic null）、`model`（粒子の運動のモデル、basic change） |
| | `state-2` 融点と沸点 | 融点（固体→液体）・沸点（液体→気体）は物質ごとに決まっている（水 0℃・100℃、エタノール沸点 78℃）。加熱のグラフ: 状態が変わっている間は温度が一定（横ばい）。純粋な物質は温度が一定になる。 | `point`（融点・沸点とグラフ、basic change） |
| `distill` 混合物を分ける (order 2) | `state-3` 混合物と純粋な物質 | 純粋な物質（1 種類）と混合物（2 種類以上: 空気、海水、みりん）。混合物は沸点が一定にならない（グラフが横ばいにならない）。 | `mixture`（純粋な物質と混合物、basic point） |
| | `state-4` 蒸留 | 蒸留: 液体を加熱して出てきた気体を冷やして液体に戻し、集める。沸点の低いものが先に出る（水とエタノールの混合物 → 最初にエタノールを多くふくむ液体）。沸とう石を入れる理由、温度計の球の位置（枝の高さ）、ガラス管の先を液体につけない理由。 | `distill`（蒸留、basic mixture） |

## 図のアイデア

- 粒子モデル: `rect` の枠に `circle` を並べる（固体は格子状、液体は乱雑に密、気体はまばら）。「気体の粒子はどれ」を figure-choice。
- 加熱のグラフ: 軸 `line` と折れ線 `line`（0℃ の横ばい → 上昇 → 100℃ の横ばい）。`region` で「氷がとけている最中」の区間を選ぶ。
- 蒸留の装置: 枝付きフラスコ（`polygon`＋`line`）、`flame`、温度計 `line`、ガラス管 `line`、試験管 `tube`（`beaker` に氷水）。`region` ア〜ウで「温度計の球を置く位置」を選ぶ。
- drag: 「温度計の球を枝の高さに動かす」（axis 'y'）、「ガラス管の先を液面の上に動かす」（axis 'y'）。

## 計算・数値

- 水の融点 0℃、沸点 100℃、エタノールの沸点 78℃（`number`、`tolerance: 0`、`unit: '℃'`）。
