## 反映の形（決めたこと）

1. 各単元に**領域「ミニプリント」**（`id: 'miniprint'`, `order` は既存の最後＋1）を足し、その中に**ステージ「プリント 1」「プリント 2」…**（`id: '<単元id>-mp1'`, `-mp2`…、`title` は内容が分かる名前。例「プリント 1: 顕微鏡の使い方」）を置く。1 ステージは **プリント 2〜4 枚ぶん**（問題 4〜6 問 ＋ retryPool）。プリントの並びは文字起こしの順（学ぶ順）。
2. **プリントの小問 1 つ → 問題 1 問以上**。同じことを聞く小問はまとめてよい。入れる場所は、ステージの `problems`（4〜6 問。うち 1 問は `term: true` の用語問題、1 問以上は figure-choice か drag）→ あふれた分は同じステージの `retryPool`（概念ごとに 2 問以上）→ さらにあふれた分は概念の `checkPool` に足す。**プリントの問題を 1 問も落とさない**（落とすときは報告に理由を書く）。
3. 概念: 既存の概念に当てはまるものはその id を使う。既存の概念で表せない内容（例: 電流と磁界の「モーター・電磁誘導」、観察器具）は**新しい概念**を足す（id は単元の接頭辞つき、`basic` は前提の既存概念、`lessonStageId` はそのプリントのステージ、`checkPool` 3 問以上）。
4. カード: 各ステージに 2〜3 枚（40〜160 字、用語は `**語**`）。プリントの内容の要点を復習する文。図は汎用の部品で簡単に描く（validateUnit と content-all が「カードに図がある」を求める）。動く図（anim）・写真は足さない。
5. 〔図〕が核になる問題: (a) 汎用の部品で簡略図が描けるもの（器具の部分名、回路、装置、断面）は `figureChoice`（region で選ばせる）か `drag` で作る。(b) 作図（方眼・光線・柱状図）やグラフの読み取りで図が描けないものは、文で成立する形（「〜のとき、像はどうなる？」「数値表から読む」）に変える。(c) どうしても成立しないものは report に「見送り」と理由を書く。
6. 数値計算の問題は `fill` の `number`（`tolerance` は 0 か、割り切れないときは 0.1）。単位を `unit` に。
7. 2 年「天気」「磁界」「3 年③」など **解答付き** のプリントは、その解答を正解にする。答え未記入のものは自分で正しい答えを付け、迷ったものは report の「自信のない点」に書く。
8. 文はすべて自分の言葉で書き直す（プリントの文をそのまま写さない）。教科書の図・文を写さない。
9. id の付け方: 問題 `<単元id>-mp<n>-p<k>`（用語 `-t<k>`、warmup `-w1`、retryPool `-r<k>`）、カード `<単元id>-mp<n>-c<k>`、新しい概念の確認問題 `<概念id>-k<k>`。既存の id と重ねない（tests/content-all が全単元で一意を検査する）。
10. `docs/reports/content/<単元>.md`（先生の確認用一覧）に、新しいステージの節を既存と同じ形で足す（カード、問題の表、プリントのファイル名を「参考:」に）。末尾に「自信のない点（先生に確認してほしい）」と「見送ったプリント」を足す。
