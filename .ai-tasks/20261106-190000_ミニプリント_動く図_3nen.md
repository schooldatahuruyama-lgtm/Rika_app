2. 新しい kind は分野のファイル（`js/anim-physics.js`・`anim-chem.js`・`anim-bio.js`・`anim-earth.js`）に `register(kind, frame, { restT, period })` で足す。描き方は `docs/anim-guide.md` と既存の kind に合わせる（静止図と `frame(kind, restT)` の text・label を同じにする決まりは新規の kind に適用される）。
3. `tests/anim-*.test.js` に新しい kind の検査を既存と同じ形で足す。`docs/anim-plan.md` の末尾に「ミニプリント（3nen）」の節として足した kind の一覧を書く。
4. headless Edge で新しい kind を 3 本以上目で確かめる（内蔵ブラウザは使わない）。`npm test` 全件成功。
