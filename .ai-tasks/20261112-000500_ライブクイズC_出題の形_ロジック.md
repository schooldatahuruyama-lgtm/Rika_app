作成: Claude Code（Fable）2026-11-12。実装: Opus。レビュー: Codex。設計: 設計書 14 章への追加。画面は指示書 D で作る。この指示書は **Node でテストできる部分**（`js/live.js` と `tests/live.test.js`）だけ。
ユーザー指示: 「リアルタイムの問題を解くときの方式が選択式ばかりだったので、出題の仕方をもう少し工夫して: 複数回答・自由記述・並び替え」。

## 決めたこと

1. 問題に `kind` を足す: `'choice'`（今までの選択式。`kind` が無い古い部屋の問題は choice とみなす）、`'multi'`（複数回答: あてはまるものを全部選ぶ）、`'text'`（自由記述: 短い語や数を打つ）、`'order'`（並びかえ: 選択肢を正しい順に並べる）。
2. **データベースの規則は変えない**（`answers/<qid>/<pid>` の `choice` は文字列のまま。先生が規則を貼り直さなくてよい）。そのため答えはすべて文字列に符号化する:
   - choice: 選択肢の id（`'a'`）
   - multi: 選んだ id を a→d の順に並べ `','` で結ぶ（`'a,c'`）。問題の `answer` も同じ形（正解の id を a→d 順）
   - order: 並べた順の id を `','` で結ぶ（`'c,a,b'`）。問題の `options` は**生徒に見せる順（シャッフル済み）**、`answer` は正しい順の id を `','` で結んだもの
   - text: 打った文字列そのもの（前後の空白を取る。`MAX_TEXT_ANSWER = 40` 文字まで）。問題の `answer` は正解の文字列の代表（`accept[0]`）、`accept` は別解をふくむ正解の配列
3. 正誤は `isCorrect(question, answer)`（下記）で決める。multi は**全部一致したときだけ正解**（部分点なし）、order は順が全部一致、text は正規化して一致（数の答えは許容誤差つき）。得点は今までどおり正解 500 + 速さ 500。
4. 教材の問題の取りこみ: 選択式（`choice`）に加え、**空欄が 1 つだけの穴埋め（`fill`）を text として取りこむ**。`word` の空欄は `accept: [answer]`、`number` の空欄は `number: { value: answer, tolerance }` と `accept: [String(answer)]`。
5. 得点・順位・学習記録の流れ（`applyScores`・`scoreUpdate`・`leaderboard`・`recordEvents`・`pendingRecords`）は形を変えず、正誤の判定だけ `isCorrect` に寄せる。

## js/live.js の変更

```js
// 定数
KINDS = ['choice', 'multi', 'text', 'order']
MAX_TEXT_ANSWER = 40        // 自由記述の答えの長さ
MAX_ACCEPT = 5              // 自由記述の正解（別解をふくむ）の数
kindOf(q) → q.kind が KINDS にあればそれ、無ければ 'choice'

// 自由記述の正規化: NFKC（全角の英数・記号を半角に）→ 小文字 → 空白をすべて除く → 末尾の「。」「．」「.」を除く
normalizeText(s) → string（文字列でなければ ''）

// 答えの文字列を問題の形に合わせて整える。合わなければ null
//   choice: options にある id だけ。multi: ',' で分けた id がすべて options にあり、重なりなし、1 つ以上。a→d 順（options の順）に並べ直した文字列を返す
//   order: ',' で分けた id が options の id のちょうど並べかえ（全部・重なりなし）。text: 文字列を trim し MAX_TEXT_ANSWER 文字まで、空なら null
cleanAnswer(question, value) → string | null

// 正誤。answer は文字列か { choice, at } のどちらでも（choiceOf を通す）。cleanAnswer で null になる答えは不正解
//   choice: id が一致。multi: cleanAnswer 後の文字列が question.answer と一致（'c,a' と 'a,c' は同じ）。order: 文字列が一致
//   text: question.number があれば Number(normalizeText(v)) が value ± tolerance（数にできなければ不正解）、無ければ accept のどれかと normalizeText が一致
isCorrect(question, answer) → boolean

// 集計。choice と multi は選択肢ごとの人数（multi は選んだ id をそれぞれ数える）。text と order は答えごとの人数
//   groups: [{ value（代表の生の文字列。text は normalizeText が同じものをまとめ、最初に出た生の文字列を代表に）, count, correct }] を count の多い順に
//   choice / multi では groups は []。total は答えた人数（cleanAnswer が null の答えは数えない）、correctCount は isCorrect の人数
tally(question, answers) → { counts, total, correctCount, groups }

// 教材の問題から。choice は今までどおり。fill は blanks が 1 つだけのとき text として取りこむ:
//   prompt = (problem.prompt を trim) + ' ' + (problem.text の '[<id>]' を '（　　）' に置きかえたもの)。'**' はそのまま（画面側の plain が外す）。MAX_PROMPT を超えたら null
//   word: accept = [String(blank.answer).trim()]、number: number = { value: blank.answer, tolerance: blank.tolerance が数なら それ、無ければ 0 }、accept = [String(blank.answer)]、unit があれば prompt の末尾に '（' + unit + ' で答える）' を足す
//   options は []、answer = accept[0]。kind: 'text'。それ以外の type（figure-choice・drag など）や blanks が 2 つ以上の fill は null
questionFromProblem(problem, where) → question | null

// 先生が書く問題。input.kind（無ければ 'choice'）で分ける。random は 0〜1 の関数（order のシャッフル用。省略時 Math.random）
//   choice: 今までどおり（options 文の配列、answer 番号）
//   multi: input.answers = 番号の配列（1 つ以上、文のある選択肢だけ）。answer は id を a→d 順に ',' で結ぶ。選択肢は 2〜4
//   order: input.options = 正しい順の文（2〜4 つ。空は落とす。2 つ以上）。options は random でシャッフルした表示順に id を a, b, c… と付け直す（id は表示順）。answer は正しい順の id。シャッフルの結果が正しい順と同じなら末尾を先頭に回す（2 つ以上なら必ず変わる）
//   text: input.accept = 文字列の配列（trim して空を落とす。1〜MAX_ACCEPT。重なりは落とす）。options は []、answer = accept[0]。number は付けない
//   どの形も prompt が空なら null。戻り値に kind を入れる
customQuestion(input, n, random) → question | null

// safeQuestion: kind を守る（KINDS に無ければ 'choice'）。choice / multi / order は options（cleanOptions）が要り、answer が cleanAnswer を通ること。
//   text は options を [] にし、accept（文字列の配列、空を落として 1〜MAX_ACCEPT。無ければ [answer]）と number（{ value, tolerance } が数なら残す。無ければ null）を守る。answer が空なら null
// pendingRecords: 「選択肢にない答えは入れない」を cleanAnswer(q, choice) === null なら入れない、に。correct は isCorrect
// scoreFor・applyScores・scoreUpdate: 正誤を isCorrect に。それ以外は変えない
// recordEvents: 変えない（choice は符号化した文字列のまま渡す）
```

## tests/live.test.js に足すテスト

- `questionFromProblem`: 空欄 1 つの word の fill → kind text、prompt に '（　　）'、accept、options []。number の fill → number と unit の文。空欄 2 つの fill → null。
- `customQuestion`: multi（answers [0, 2] → answer 'a,c'、answers [] → null）、order（random を固定して表示順が変わること、answer が正しい順、表示順が正しい順と同じになる random でも answer と options の順がちがうこと、1 つだけなら null）、text（accept の trim・空落とし・重なり落とし、6 つ以上は 5 つまで、全部空なら null）。
- `normalizeText`: 全角「ＡＢＣ １２」→ 'abc12'、末尾の「。」、空白、大文字。
- `cleanAnswer` / `isCorrect`: multi の順ちがい（'c,a' → 'a,c'、正解）、足りない・多い → 不正解、知らない id → null。order の一致・不一致・重なり → null。text の正規化一致、別解、number の許容誤差（value 7.5, tolerance 0.1 で '7.4' 正解・'7.3' 不正解・'七' 不正解）、41 文字 → null。
- `scoreFor`: multi と text で正解のとき 500 以上、不正解 0。
- `tally`: multi で選んだ id がそれぞれ数えられる（'a,c' が 2 人なら a と c が 2 ずつ、total 2）。text で groups がまとまる（'双眼実体顕微鏡' と '双眼実体顕微鏡。' が同じ group、correct true）。order の groups。
- `pendingRecords`: multi・text・order の答えが入り、cleanAnswer が null の答えは入らない。
- `safeQuestion`（safeRoom 経由）: kind の無い古い問題は choice、text の問題は options 無しでも残る、kind が変でも choice に落ちる。
