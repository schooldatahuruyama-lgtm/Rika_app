## 判断した点

- **公開版と同じ id はためせない**（register で公開版を置きかえ、やめるときに unregister で消してしまうため）。ステージ・概念の id がほかの単元と重なるときも入れない。起動時にためせなくなった下書きは preview を外して保存。
- ためし中の下書きを編集したら登録し直す。決まりに合わなくなったら、ためすを止めて message。
- **確認済みにするには照合が空であること**も条件にした（書き出した教材が壊れないように）。確認済みの下書きを編集・生成すると「下書き」に戻す。
- 計画は normalizePlan の errors が空のときだけ入れる（指示書どおり）。計画を作り直すとステージは空に戻す（確認ダイアログ）。ステージは normalizeStage の errors があっても入れ、その場に「確かめてください」と出す（照合で続けて見られ、編集で直せるため）。
- プリント: テキストは下書きに保存（500 KB まで）、PDF・画像は base64 が大きいのでメモリだけ（10 MB まで）。開き直したら「選び直しが必要」と出し、API 生成を止める。
- モデルの select は新しく作るフォームと下書きの「入力」card に置いた（下書きごと）。
- 編集は change（確定）で保存し、照合と公開の card だけ描き直す（入力中にフォーカスが消えないように）。足す・消すは全体を描き直す（スクロール位置は保つ）。
- ctx.author に `builtinIds()` を足した（id の注意と、ためすの判定に使う）。
- 穴埋めの文・空らん（言葉の選択肢・正解、数の正解・単位）も編集できるようにした。
