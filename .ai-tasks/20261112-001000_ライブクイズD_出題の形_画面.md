# 実装指示書 D: ライブクイズ — 出題の形を増やす（先生と生徒の画面）

作成: Claude Code（Fable）2026-11-12。実装: Opus。レビュー: Codex。前提: 指示書 C（`js/live.js` の `kindOf`・`normalizeText`・`cleanAnswer`・`isCorrect`・`tally` の `groups`・`questionFromProblem` の fill 取りこみ・`customQuestion` の kind）が済んでいる。**関数名と戻りの形は実際の `js/live.js` を読んで合わせる**。

## 形ごとの画面

答えの符号化（`js/live.js` と同じ）: choice `'a'`、multi `'a,c'`（a→d 順）、order `'c,a,b'`（表示順の id を並べた順）、text 文字列。ラベル `LABELS = ['ア','イ','ウ','エ']` は options の並び（表示順）に対応する。

| kind | 先生: 出題中 | 生徒: 回答 | 答え合わせ（先生） | 答え合わせ（生徒） |
|---|---|---|---|---|
| choice | 今までどおり | 今までどおり | 今までどおり | 今までどおり |
| multi | 選択肢 4 つ＋「あてはまるものを全部」の印（`live-kind`） | 選択肢を**押すたびに選ぶ／外す**（`aria-pressed`、`is-picked`）。下に「決定（N こ）」ボタン（1 つ以上で有効）。決定で `answer(j, q, 'a,c')`（`L().cleanAnswer(q, …)` を通した文字列）。決定後は今までどおり disabled と「答えた！」 | 選択肢ごとの横棒（正解の選択肢は全部 `is-correct`）。「正解: ア・ウ」 | ○/×、「正解: ア・ウ」、「あなた: ア」 |
| text | 問題文と「（記述）」の印。選択肢なし | 1 行の入力欄（`maxlength` = `L().MAX_TEXT_ANSWER`、`autocomplete=off`。`q.number` があれば `inputmode="decimal"`）＋「送る」。Enter でも送る。空なら送らない。送ったあとは入力欄を disabled にし「答えた！」 | `tally().groups` の上位 5 件を「答え — N 人」の一覧（正解は緑 `is-correct`）。「正解: ○○（別解: …）」 | ○/×、「正解: ○○」、「あなた: △△」 |
| order | 選択肢を表示順（ア〜エ）で出し「正しい順に並べる」の印 | 選択肢を**正しい順にタップ**する（タップした順に 1, 2, 3… の番号 `live-order-num` が付き、その選択肢は押せなくなる）。「やり直す」で番号を消す。全部タップしたら「決定」が有効 → `answer(j, q, 'c,a,b')` | 「正解: ウ → ア → イ」と、`groups` 上位 5 件を「ウ → ア → イ — N 人」で一覧（正解は緑） | ○/×、「正解: ウ → ア → イ」、「あなた: ア → ウ → イ」 |

- 生徒の送信中の表示（`j.answering[q.id]`）・送れなかったときの「もう一度送る」（`j.sendFail.choice`）は今の仕組みのまま、符号化した文字列を使う。
- 時間切れ（`remaining <= 0`）では multi の決定・text の送る・order の決定も押せない。
- `myChoice(j, q)` の戻りは符号化した文字列のまま。表示用に `answerText(q, value)`（kind ごとに「ア・ウ」「ウ → ア → イ」「文字列」にする小さな関数）を生徒・先生の両方に置く（同じ内容でよい）。
- 正誤は `L().isCorrect(q, mine)` で（`mine === q.answer` の比較は使わない）。

## 先生の「自分で書く」

- 先頭に **出題の形** の select（`live-custom-kind`）: 「選択式（1 つ選ぶ）」「複数回答（あてはまるもの全部）」「自由記述（語や数を打つ）」「並びかえ（正しい順に）」。`draft.kind`。変えたら描き直す。
- choice: 今までどおり（選択肢 4 つ＋正解の select）。
- multi: 選択肢 4 つ＋「正解（あてはまるもの全部）」のチェックボックス 4 つ（`draft.answers` = 番号の配列）。
- order: 「正しい順に 2〜4 つ」の入力 4 つ（`draft.options`。上から正しい順）。案内「生徒には順をまぜて出します」。
- text: 「正解」の入力 1 つ＋「別解（なくてもよい）」の入力 2 つ（`draft.accept` 3 つ）。案内「空白・全角半角・大文字小文字・末尾の「。」はちがっていても正解になります」。
- 「足す」は `L().customQuestion({ kind, prompt, options, answer, answers, accept }, sel.customN + 1)`。null なら形ごとの案内文（choice: 今の文。multi: 「問題文と 2 つ以上の選択肢を入れ、正解を 1 つ以上チェックしてください」、order: 「問題文と、正しい順に 2 つ以上の選択肢を入れてください」、text: 「問題文と正解を入れてください」）。
- 「3. 選んだ問題」の一覧: 自作・教材とも、形の印を付ける（choice は無印、multi「複数回答」、text「記述」、order「並びかえ」）。
- 「2. 問題を選ぶ」: ステージの行は「（選択式 N 問・記述 M 問）」（M が 0 なら「（選択式 N 問）」）。案内文を「ステージを選ぶと、その選択式の問題と、空欄が 1 つの穴埋めの問題（記述）が入ります（図だけの問題と長い問題は入りません）。」に。
