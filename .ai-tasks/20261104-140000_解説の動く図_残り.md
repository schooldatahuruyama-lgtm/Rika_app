## 1. `js/anim.js` に足す共通の道具（モジュール内部。テストのために `helpers` として公開してよい）

- `clamp01(x)`: 0〜1 に収める。
- `stage(t, from, to)`: `clamp01((t - from) / (to - from))`。「t が from から to の間に 0→1 に進む」。
- `lerp(a, b, u)`: `a + (b - a) * u`。
- `grow(points, p, opts)`: 折れ線 `points = [[x, y], ...]` を、全長に対する割合 `p`（0〜1）まで描いた ray item の配列を返す。各辺を 1 本の `ray` にし、途中の辺は `arrow: false`、**いちばん先の（途中まで描いている）辺だけ `arrow: true`**。`p` が 0 なら空配列。`opts.dashed` が true なら全部 `dashed: true`。長さ 0 の辺は飛ばす。p = 1 で全辺を描き、最後の辺に矢印。
- `deg(x)`: 度 → ラジアン。`rad2deg`。
- `u(t)`: `0.5 - 0.5 * Math.cos(2 * Math.PI * t)`（0→1→0 のゆっくりした往復。試作の `c` と同じもの）。

屈折率は `N = { water: 1.33, glass: 1.5 }`。スネルの法則は `sin(θ2) = sin(θ1) * n1 / n2`。

以下、座標は x 右向き・y 下向き、場面 320×240。`L` は光線の長さ。角度は度で書き、計算はラジアン。静止図（`content/light.js` の `figure`）に同じ item があればそれと同じ座標・文字を使う。「静止 item」= その kind で動かさない item（静止図からそのまま持ってくる）。

## 2. 足す kind（21 種）とカードの対応

### 光の直進

**`rays-spread`**（straight-1-c1）: 電球から 5 本の光の道すじが同時に伸びる。`p = stage(t, 0, 0.7)`。静止図の 5 本の ray それぞれを `grow([[80,120],[x2,y2]], p)` で描く。静止 item: lamp、label 2 つ。

**`shadow-forms`**（straight-1-c2）: 光源から物体の上下のはしを通る 2 本の光がスクリーンまで伸び、届いたところで影ができる。`p = stage(t, 0, 0.6)`。ray: `grow([[40,120],[280,51]], p)`、`grow([[40,120],[280,189]], p)`。`p >= 1` のとき `shadow { x: 280, y1: 51, y2: 189 }` と label (290,126) '影' を足す。静止 item: object (140,149,58,'物体')、screen、lamp。順: ray → object → screen → shadow → lamp → label。

**`light-to-eye`**（straight-2-c1）: 電球の光が目に向かって進む。`p = stage(t, 0, 0.6)`。`grow([[70,120],[240,120]], p)`。`p >= 1` で label (120, 90) '光が目に入る → 見える'。静止 item: lamp、eye、label '光源'、label '目'。

**`bounce-to-eye`**（straight-2-c2）: 光源の光が本に当たり、はね返って目に入る。`p1 = stage(t, 0, 0.4)`、`p2 = stage(t, 0.4, 0.8)`。`grow([[60,60],[158,160]], p1)`、`grow([[162,160],[255,92]], p2)`。`p2 >= 1` で label (236,120) '見える！'。静止 item: lamp、object (160,200,40,'本')、eye、label '光源'。

### 光の反射

**`reflect-travel`**（reflect-1-c1）: 入射光が鏡に当たり、反射光として進む。`p1 = stage(t, 0, 0.45)`、`p2 = stage(t, 0.45, 0.9)`。`grow([[60,60],[160,180]], p1)`、`grow([[160,180],[260,60]], p2)`。静止 item: mirror、lamp、label 3 つ（入射光・反射光・鏡）。順: mirror → ray → lamp → label。

**`reflect-names`**（reflect-1-c2）: 入射角が 25°〜45° でゆっくり変わり、法線・入射角・反射角の文字はそのまま。`theta = 25 + 20 * u(t)`、`L = 110`、H = (160,180)。入射光 `(160 − L sinθ, 180 − L cosθ) → H`、反射光 `H → (160 + L sinθ, 180 − L cosθ)`（どちらも arrow）。静止 item: mirror、normal {x:160,y:120,angle:0}、label '法線' (166,54)、'入射角' (100,95)、'反射角' (172,95)。

**`mirror-image-distance`**（reflect-2-c1）: ものを鏡に近づけたり離したりすると、像も同じだけ動く。`ox = 90 + 40 * u(t)`（90〜130）、`ix = 320 − ox`（鏡 x = 160 について対称）。object (ox, 190, 60, 'もの')、object (ix, 190, 60, '像')、dashed ray `{x1: ox, y1: 150, x2: ix, y2: 150, dashed: true}`（arrow なし）、label 'a' を ((ox+160)/2 − 4, 144) と ((160+ix)/2 − 4, 144)。静止 item: mirror (160,40)-(160,210)、label '鏡からの距離はどちらも a'。

**`image-behind-mirror`**（reflect-2-c2）: ものから出た光が鏡で反射して目に入り、反射光をのばした先に像が見える。`p1 = stage(t, 0, 0.3)`、`p2 = stage(t, 0.3, 0.6)`、`p3 = stage(t, 0.6, 0.9)`。`grow([[90,170],[160,125]], p1)`、`grow([[160,125],[72,67]], p2)`、`grow([[160,125],[230,170]], p3, { dashed: true })`。`p3 >= 1` で object (230,200,30,'像') を足す。静止 item: mirror (160,30)-(160,220)、object (90,200,30,'もの')、eye (60,60)。

**`mirror-visible`**（reflect-2-c3）: 像の位置が B（見えない）から A（見える）へ動き、像と目を結ぶ直線が鏡の面を通るかどうかで文字が変わる。`P = (lerp(200, 210, u), lerp(30, 100, u))`（u = u(t)。B (200,30) → A (210,100)）。直線 目 (60,120) → P が x = 160 を通る y: `yAt = 120 + (P.y − 120) * (100 / (P.x − 60))`。`visible = yAt >= 80 && yAt <= 160`（鏡は y 80〜160）。dashed ray (60,120) → P（arrow なし）、point P（label なし）、label (30,200): visible なら '鏡の面を通る → 見える'、そうでなければ '鏡の外を通る → 見えない'。静止 item: mirror (160,80)-(160,160)、eye (60,120)、point 像A (210,100)、point 像B (200,30)。

### 光の屈折

**`refract-in`**（refract-1-c1）: 空気から水へ。入射角 20°〜50°。`theta1 = 20 + 30 * u(t)`、`sinθ2 = sinθ1 / 1.33`、H = (140,120)、`L = 110`。入射光 `(140 − L sinθ1, 120 − L cosθ1) → H`、屈折光 `H → (140 + L sinθ2, 120 + L cosθ2)`、まっすぐ進んだ場合の点線 `H → (140 + 90 sinθ1, 120 + 90 cosθ1)`（dashed、arrow なし）。label (170,215) '法線に近づく'。静止 item: boundary {y:120, upper:'air', lower:'water'}、normal {x:140,y:120,angle:0}、label '法線' (146,72)。順: boundary → normal → 点線 → 入射光 → 屈折光 → label。

**`refract-out`**（refract-1-c2）: 水から空気へ。水中の入射角 15°〜35°。`theta1 = 15 + 20 * u(t)`、`sinθ2 = 1.33 sinθ1`、H = (140,120)。入射光 `(140 − L sinθ1, 120 + L cosθ1) → H`、屈折光 `H → (140 + L sinθ2, 120 − L cosθ2)`、点線 `H → (140 + 90 sinθ1, 120 − 90 cosθ1)`。label (200,215) '法線から離れる'。静止 item: boundary (air/water, y 120)、normal (140,120)、label '法線' (100,70)。

**`vertical-vs-oblique`**（refract-1-c3）: 垂直に入る光は曲がらず、ななめの光だけ折れる。2 本が同時に進む。`p = stage(t, 0, 0.8)`。垂直 `grow([[110,20],[110,220]], p)`、ななめ `grow([[190,30],[240,110],[282,220]], p)`。静止 item: boundary {y:110, upper:'air', lower:'glass'}、normal (240,110)、label '垂直' (118,70)、'ななめ' (196,24)。

**`coin-lift`**（refract-2-c1）: コインからの光が水面で折れて目に届き、のばした先にコインが浮いて見える。`p1 = stage(t, 0, 0.35)`、`p2 = stage(t, 0.35, 0.7)`、`p3 = stage(t, 0.7, 0.95)`。`grow([[110,200],[160,100]], p1)`、`grow([[160,100],[205,39]], p2)`、`grow([[160,100],[110,168]], p3, { dashed: true })`。`p3 >= 1` で point (110,168) と label (8,172) '浮いて見える'。静止 item: boundary (air/water, y 100)、eye (214,27)、point (110,200)、label 'コイン' (50,206)。

**`stick-lift`**（refract-2-c2）: 棒の先からの光が水面で折れ、見える位置が浮き上がる。`p1 = stage(t, 0, 0.35)`、`p2 = stage(t, 0.35, 0.7)`、`p3 = stage(t, 0.7, 0.95)`。`grow([[100,210],[150,100]], p1)`、`grow([[150,100],[188,42]], p2)`、`grow([[150,100],[100,176]], p3, { dashed: true })`。`p3 >= 1` で point (100,176) と label (14,182) '見える位置'。静止 item: boundary (y 100)、object (100,210,170,'棒の先')、eye (196,30)。

**`total-reflection`**（refract-2-c3）: 水中の入射角が 30°〜60° で変わり、臨界角（`asin(1/1.33)` ≒ 48.75°）を超えると全反射になる。`theta = 30 + 30 * u(t)`、H = (180,100)、`L = 110`。入射光 `(180 − L sinθ, 100 + L cosθ) → H`（arrow）。lamp をその始点に置く。
- `sinθ * 1.33 < 1` のとき: 屈折光 `H → (180 + 90 sinθ2, 100 − 90 cosθ2)`（`sinθ2 = 1.33 sinθ`、arrow）と、弱い反射光 `H → (180 + 70 sinθ, 100 + 70 cosθ)`（dashed、arrow）。label (10,215) '空気中へ出る（一部は反射）'。
- それ以外（全反射）: 反射光 `H → (180 + L sinθ, 100 + L cosθ)`（arrow、実線）だけ。label (10,215) '全反射！ 入射角 ＝ 反射角'。
- label (10,40) `'入射角 ' + Math.round(theta) + '°'`。静止 item: boundary (y 100)、normal (180,100)。

### 凸レンズ

**`lens-parallel-rays`**（lens-1-c1）: 光軸に平行な 3 本の光がレンズに入り、焦点に集まる。`p = stage(t, 0, 0.8)`。`grow([[20,80],[160,80],[280,160]], p)`、`grow([[20,120],[160,120],[290,120]], p)`、`grow([[20,160],[160,160],[280,80]], p)`。静止 item: axis (120)、lens {cx:160,cy:120,height:140,f:60}、label '光軸' (10,112)、'焦点' (206,166)。順: axis → lens → ray → label。

**`focal-length`**（lens-1-c2）: ふくらみの大きいレンズほど焦点距離が短い。`f = 60 − 20 * u(t)`（60〜40）、`bulge = 15.4 + 10 * u(t)`（lens の新しい項目、下の 3 を参照）。lens {cx:160,cy:110,height:140,f, bulge}。平行光 `(20,70) → (160,70)`、屈折光 `(160,70) → (280, 110 + 40 * 120 / f)`（焦点 (160+f, 110) を通る直線。f = 60 で y 190、f = 40 で y 230）。目盛: normal {x:160,y:212,angle:90}、point (160−f, 212)、(160,212)、(160+f, 212)。label '焦点距離' を (160 − f/2 − 32, 203) と (160 + f/2 − 32, 236)。静止 item: axis (110)。

**`lens-special-rays`**（lens-1-c3）: 中心を通る光はまっすぐ、焦点を通ってから入った光は光軸に平行に進む。`p = stage(t, 0, 0.8)`。`grow([[40,60],[160,120],[280,180]], p)`、`grow([[60,150],[160,75],[300,75]], p)`。静止 item: axis、lens {160,120,140,f:60}、label 'まっすぐ' (200,214)、'光軸に平行' (196,64)。

**`real-image-forms`**（lens-2-c1）: 物体の先からの光がレンズを通って集まり、スクリーンに実像ができる。`p = stage(t, 0, 0.75)`。`grow([[40,70],[160,70],[220,145]], p)`、`grow([[40,70],[220,145]], p)`。`p >= 1` で object (220,120,−25) と label (232,176) '実像'。静止 item: axis、lens {160,120,140,f:40}、screen (220, 40〜200)、object (40,120,50,'物体')。

**`image-size-by-distance`**（lens-2-c2）: 物体を動かすと像の位置と大きさが変わる。f = 40、h = 40。`d_o = 90 − 30 * cos(2πt)`（60〜120）、`d_i = 1 / (1/f − 1/d_o)`、`ox = 160 − d_o`、`sx = 160 + d_i`（スクリーンは像の位置に動く）、像の高さ `hi = h * d_i / d_o`（下向きなので object の height は `−hi`）。object (ox, 120, 40, '物体')、screen (sx, 40〜200)、ray `(ox,80) → (160,80)`、`(160,80) → (sx, 80 + d_i)`（焦点 (200,120) を通る直線）、`(ox,80) → (sx, 120 + hi)`（中心を通る直線）、object (sx, 120, −hi)。label (10,230): `|d_o − 80| < 4` なら '焦点距離の 2 倍 → 同じ大きさ'、`d_o < 80` なら '焦点に近づける → 像は大きい'、それ以外 '遠ざける → 像は小さい'。静止 item: axis、lens {160,120,140,f:40}。

**`virtual-image`**（lens-2-c3）: 物体を焦点の内側に置くと、レンズを通った光をのばした先に大きな虚像が見える。`p1 = stage(t, 0, 0.4)`、`p2 = stage(t, 0.45, 0.75)`。`grow([[140,90],[170,90],[290,162]], p1)`、`grow([[140,90],[250,200]], p1)`、`grow([[170,90],[95,45]], p2, { dashed: true })`、`grow([[170,120],[95,45]], p2, { dashed: true })`。`p2 >= 1` で object (95,120,75) と label (62,166) '虚像'。静止 item: axis、lens {170,120,140,f:50}、object (140,120,30)、eye (300,190)、label '物体' (112,166)。
