## js/live.js（IIFE＋module.exports。`require('./xp.js')`・`./record.js` を使ってよい）

```js
// 部屋コード: 読みまちがえにくい英大文字・数字（I, O, 0, 1 を除く）6 文字
newRoomCode(random) → 'A7K3PX'（random は 0〜1 の関数。省略時 Math.random）
newPlayerId(random) → 'p' + 8 文字
// 教材の問題から出題用の形へ（選択式だけ。figure のある問題は図を落として文だけ。prompt が 120 字を超えるものは除く）
questionFromProblem(problem, { unitId, stageId }) → { id, prompt, options: [{ id, text }], answer, conceptId, unitId, source: 'content' } | null
customQuestion({ prompt, options: [文...], answer: 0〜3 }) → { id: 'c-<n>', prompt, options, answer: 'a'…, conceptId: null, source: 'custom' } | null（文が空・選択肢 2 未満は null）
// 部屋の初期データ
newRoom({ code, title, questions, seconds（既定 20、5〜120）, hostId }, now) → { meta: { createdAt, title, status: 'lobby', seconds, hostId, count: n }, questions: {…id→q}（配列ではなく id をキーにした object。REST で配列が崩れないため。順番は order で）, state: { index: -1, phase: 'lobby', startedAt: null, seconds } }
// 得点: 正解 500 ＋ round(500 × 残り時間の割合)。残り時間は seconds − (at − startedAt)/1000（負なら 0）。不正解は 0。at・startedAt は ms
scoreFor(question, answer, startedAt, seconds) → 0〜1000
// 1 問ぶんの集計。answers = { pid: { choice, at } }
tally(question, answers) → { counts: { a: n, b: n… }, total, correctCount }
// 得点の合計を更新（players の score に足す）。players = { pid: { name, score } }
applyScores(players, question, answers, startedAt, seconds) → 新しい players（元を変えない）
leaderboard(players) → [{ pid, name, score, rank }]（score 降順、同点は同じ rank、name 順）
// 生徒側: 教材の問題に答えた分を学習記録に入れる出来事（record.applyEvents に渡す配列）。custom は XP だけ
recordEvents(question, choice, correct, sessionId) → [{ kind: 'history', phase: 'live', … }, { kind: 'answer' }, correct ? { kind: 'correct' } : null, question.conceptId ? { kind: 'mastery', change: … } : null]（phase は 'live'。mastery の change は config.mastery.later（正解）か wrong）
// 受信した部屋データの守り（形の崩れた値を既定に）
safeRoom(raw) → { meta, questions（order 順の配列）, state, players, answers }（どれも欠けていれば空）
isStale(meta, now) → createdAt から 24 時間以上
// 状態遷移（先生）
nextState(state, questions, action: 'start' | 'reveal' | 'next' | 'end', now) → 新しい state（start: index 0 で phase 'show' startedAt now、reveal: phase 'reveal'、next: 次の index で 'show'（最後なら 'ended'）、end: 'ended'）
```

## js/live-db.js（ブラウザ向けだが Node でテストできる形）

```js
createDb({ baseUrl（例 'https://xxx-default-rtdb.firebaseio.com'。末尾の / と .json は取る）, fetchImpl, EventSourceImpl, now })
  → { put(path, data), patch(path, data), get(path), remove(path), watch(path, onData, onError) → stop(), serverTime() }
```
- `put` = `PUT <base>/<path>.json`、`patch` = `PATCH`、`get` = `GET`、`remove` = `DELETE`。body は JSON。`{ ".sv": "timestamp" }` をそのまま送るとサーバー時刻になる。失敗（status ≥ 400、ネットワーク）は `Error('通信できませんでした（…）')` で reject。403 は「データベースの規則で拒まれました（docs/live/setup.md の規則を確かめてください）」。
- `watch(path)`: `new EventSourceImpl(<base>/<path>.json)`（Firebase は `Accept: text/event-stream` で put/patch イベントを送る。EventSource が自動で付ける）。`put` イベント `{ path: '/', data }` で全体、`{ path: '/players/p1', data }` で一部を置きかえ、`patch` で一部を合成し、**最新の全体**を `onData(whole)` に渡す。`keep-alive` は無視。`cancel`・`auth_revoked` は onError。切れたら 3 秒後に再接続（最大 10 回）。`stop()` で閉じる。
- `serverTime()`: `rooms/_time/<乱数>` に `{ ".sv": "timestamp" }` を put して返り値を読み、端末時刻との差（offset）を返す（先生側が 1 回使う）。失敗は 0。
- `normalizeUrl(text)` → baseUrl か null（`https://` で始まり `firebaseio.com` か `firebasedatabase.app` を含むものだけ）。

## docs/live/firebase-rules.json

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "_time": { "$id": { ".write": true, ".read": true, ".validate": "newData.isNumber()" } },
      "$code": {
        ".read": "$code.matches(/^[A-HJ-NP-Z2-9]{6}$/)",
        ".write": "$code.matches(/^[A-HJ-NP-Z2-9]{6}$/)",
        "meta": { ".validate": "newData.hasChildren(['createdAt', 'status'])" },
        "players": { "$pid": { ".validate": "newData.hasChildren(['name']) && newData.child('name').isString() && newData.child('name').val().length <= 12" } },
        "answers": { "$q": { "$pid": { ".validate": "newData.hasChildren(['choice', 'at']) && newData.child('choice').isString()" } } }
      }
    }
  }
}
```

## docs/live/setup.md（先生向け。日本語。画面の名前は 2026 年の Firebase コンソールの日本語表示に合わせ、変わっていたら近い名前を探すよう注記）

1. https://console.firebase.google.com/ に Google アカウントで入り、「プロジェクトを追加」→ 名前（例 rika-quest）→ Google アナリティクスは「無効」でよい。
2. 左の「構築」→「Realtime Database」→「データベースを作成」→ 場所は「asia-southeast1（シンガポール）」か近い所 →「ロックモード」で開始。
3. 「ルール」タブに `docs/live/firebase-rules.json` の中身を貼って「公開」。
4. 「データ」タブの上に出る URL（`https://…-default-rtdb.….firebasedatabase.app` か `https://….firebaseio.com`）をコピー。
5. 理科クエストの先生画面 →「ライブクイズ」→「データベースの URL」に貼って保存。
6. 注意: 無料枠（同時接続 100、転送量 10 GB/月）で 1 クラスは十分。部屋コードを知っている人は書きこめるので、学校外に広めない。終わったら「終了」で部屋を消す。
