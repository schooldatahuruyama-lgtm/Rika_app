## 目的

1. 要件定義書「追加予定機能 2. ゲーミフィケーションの拡張：連続学習、バッジ、ランキングを追加する」のうち **バッジ**。連続学習は実装済み、ランキングは追加予定機能 3（サーバーが要るので今回は作らない）。
   設計書の方針「できたことを分かりやすく伝える」「正解率のみの競争としない」に沿って、取り組み（続けた・やり直した・読んだ・復習した）でも取れるバッジにする。
2. 設計書 7「記録は端末内」。ユーザーの質問「同じ端末でも別のブラウザで開くと記録は変わるか」→ 変わるので、プロフィール画面に注意書きを足す。

## js/badges.js の仕様

```js
// 定義は配列。順番がそのまま一覧の表示順
DEFS = [
  { id, title, description（取る条件を生徒向けの一文で）, glyph（メダルに描く 1〜2 文字）, color（'blue'|'green'|'orange'|'purple'|'pink' のどれか。CSS の色の名前） , test(stats) → boolean }
]
// 記録から判定に使う数をまとめる（例外を出さない。欠けている項目は 0 や空として扱う）
stats(rec, reg) → {
  clearedStages,            // status === 'cleared' のステージ数（登録済みの全ステージを reg.units() → reg.stagesInOrder(unit.id) で回す）
  clearedUnits,             // 全ステージがクリア済みの単元の数（ステージ 0 の単元は数えない）
  perfectStages,            // stars === 3 のステージ数
  totalStars,               // stars の合計
  answers,                  // history のうち phase !== 'warmup' の数
  retryCorrect,             // xpLog の kind === 'retryCorrect' の数
  learnback,                // xpLog の kind === 'learnback' の数
  lessonsRead,              // lessonsRead の true の数
  reviewedConcepts,         // reviewDone のキーの数
  masteredConcepts,         // mastery の value が config.mastery.labels の「できた」の境（0.8）以上の概念の数。境は config から読む（labels の最後から 2 番目の数値）
  bestStreak,               // history（phase !== 'warmup'）の日付（xp.localDate）を並べて、連続した日の最長の長さ
  level,                    // rec.level
}
earned(rec, reg, config) → 取れているバッジ id の配列（DEFS の順）
newlyEarned(rec, reg, config) → earned のうち rec.badges にまだ無い id の配列
award(rec, ids, now) → rec を変えずに新しい rec を返す。rec.badges[id] = { at: ISO 文字列, seen: false }（すでにあるものは変えない）
markSeen(rec, ids) → 同様に seen: true にした新しい rec
def(id) → 定義（なければ null）
```

## app.js

`commitSession(newSession, events)` で `setRecord(rec)` の前に:
```js
const fresh = RQ.badges.newlyEarned(rec, state.reg, state.config);
if (fresh.length > 0) rec = RQ.badges.award(rec, fresh, now);
```
`closeRecord` で `state.lastResult` を作るとき `newBadges: Object.keys(rec.badges).filter((id) => rec.badges[id] && rec.badges[id].seen === false)` を入れる（学習の途中で取ったものも含めて、まだ見せていないバッジ）。結果画面がそれを表示したら `markSeen` して `setRecord`（保存失敗は `reportSave` と同じ扱いで、表示は続ける）。
`normalizeRecord` は `badges` が object でなければ `{}` に戻す（`RECORD_CHECKS`）。中身の各項目は `badges.js` 側で守る（`at` が文字列でない・`seen` が boolean でないものは「取っていない」と同じ扱いにせず、**取っている**として seen: true 扱い。取り消しはしない）。

## 画面（ui-screens.js）

- **メダル** `badgeMedal(def, earnedState)`: 44px の丸い SVG（`<svg viewBox="0 0 48 48">`。外側の円＋内側の円＋glyph の `<text>`）。取っていれば `color` の色、取っていなければ灰色（`.badge-medal.is-locked`）。`aria-label` は「<title>（取った／まだ）」。glyph の文字にふりがなは付けない（`data-no-ruby`）。
- **ホーム**: 「連続学習」カードの後に `card([cardTitle('バッジ'), 取った数 / 全体数, 最近取った 3 つのメダルと名前（at の新しい順。1 つもなければ「ステージをクリアしたり、続けて学習したりすると取れるよ」）, button('バッジを見る', () => ctx.go('record'))])`。
- **結果画面**: 「できたこと」カードの直後に、`ctx.state.lastResult.newBadges` が 1 つ以上なら `card([cardTitle('新しいバッジ！'), メダルと名前と description の並び])`（`.badge-new`）。表示したら `ctx.markBadgesSeen(ids)` を呼ぶ（app.js が `ctx` に足す。`markSeen` → `setRecord` → `save`）。
- **記録画面**: 「連続学習」カードの後に `card([cardTitle('バッジ'), 取った数 / 全体数, 一覧（`ul.badge-grid`。DEFS の順に全部。各 li: メダル、title、取っていれば取った日（YYYY/M/D）、取っていなければ description）])`。
- **プロフィール画面**: 既存の注意書き「記録はこの端末のブラウザ内にだけ保存され、消えることがあります。」を「記録はこの端末の、いま使っているブラウザの中にだけ保存されます。いつも同じブラウザ・同じ URL で開いてください（別のブラウザで開くと、別の記録になります）。ブラウザのデータを消すと記録も消えます。」に変える。プロフィールが 1 つ以上あるときも同じ文を出す（新しく作るカードの中、今の位置のまま）。
- 文字は textContent。`data-no-ruby` は glyph と日付に。

## テスト

- `tests/badges.test.js`（`tests/fixtures/unit.js` と `record.js` で記録を作る）:
  - `stats`: 空の記録 → すべて 0。`finishStage` で cleared 2 回（stars 3 と 2）→ clearedStages 2、perfectStages 1、totalStars 5。history 3 日連続＋1 日空けて 2 日 → bestStreak 3。xpLog に retryCorrect・learnback を入れて数える。`history`・`xpLog`・`badges` が無い壊れた記録でも例外を出さず 0。
  - `earned` / `newlyEarned` / `award` / `markSeen`: first-clear が取れる → newlyEarned に入る → award → newlyEarned は空。award は元の rec を変えない。markSeen で seen が true。すでに取っているバッジは award で `at` が変わらない。
  - `bestStreak`: 日付をまたぐ history の `at` は ISO 文字列（`new Date(2026, 10, 3, 10)` のようにローカルで作る）。同じ日に複数あっても 1 日と数える。
  - DEFS の id が重複しない、title・description・glyph・color が全部ある、color が 5 色のどれか。
- `tests/record.test.js`: createRecord の期待値に `badges: {}`。
- `tests/teacher.test.js`: `summarizeStudent(...).badges` が数、CSV のヘッダに「バッジ」。
- `npm test` 全件成功（`tests/offline.test.js` の PRECACHE 検査も）。
