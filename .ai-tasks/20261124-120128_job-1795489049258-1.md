# 実装指示書: 上の帯のニックネームを、アバターの上下の中央にそろえる

## 目的

- 依頼: ホーム画面の上の帯に出るニックネームが、少し低く表示されているので直す。
- 要件定義書（`docs/requirements.md`）と設計書の「上の帯: いま選んでいる生徒を出す」の見た目の不具合の修正。動きや保存の形は変えない。

### 原因

- `#header-profile`（`css/style.css:156` の `.header-profile`）の中は、ふつうの行の並び（インライン）になっている。
- 中のアバター（`.avatar.avatar-small`、36px の丸）は `inline-flex` で、中の `img` が `display: block` なので、丸の下の端が文字のベースラインに乗る。
- そのため、ニックネームは丸の中央ではなく下の端にそろい、低く見える。
- 帯はすべての画面で共通なので、ホーム以外の画面でも同じずれが出ている。この修正で全部の画面が直る。

## 変えるファイルと内容

変えるのは `css/style.css` の 1 か所だけ。

### `css/style.css` の `.header-profile`（156 行目あたり）

いま:

```css
.header-profile {
  margin-left: auto;
  font-weight: bold;
}
```

変えたあと:

```css
.header-profile {
  margin-left: auto;
  display: inline-flex;
  align-items: center;
  gap: 6px;
  min-width: 0;
  font-weight: bold;
}
```

- `display: inline-flex` と `align-items: center` で、アバターの丸とニックネームを上下の中央にそろえる。同じ「アバター＋ニックネーム」を並べている `.teacher-name`（`css/style.css:1330`）と同じ書き方にする。
- `gap: 6px` は、アバターとニックネームの間隔。flex にすると `js/app.js:313` で入れている空白 `' '` は幅を持たなくなるので、間隔はここで取る（`.teacher-name` と同じ 6px）。
- `min-width: 0` は、せまい画面で長いニックネームが帯からはみ出さないようにするため（下の「端の場合」）。
- `margin-left: auto`（右寄せ）と `font-weight: bold` は、そのまま残す。
- コメントは足さない（まわりの `.app-name` や `.save-status` にもコメントがないので、合わせる）。

### 変えないもの

- `js/app.js` の `updateHeader()`（空白 `' '` も、ニックネームの `data-no-ruby` も、そのまま残す）。
- `js/ui-screens.js` の `avatarBadge()`。
- `index.html`。
- `.avatar`・`.avatar-small`・`.avatar-image`・`.header-inner` の CSS。

## 守ること

- 変えるのは `css/style.css` の `.header-profile` の規則だけ。ほかの規則・ほかのファイルは変えない。
- `.avatar` に `vertical-align` を付ける直し方はしない（プロフィール一覧やアバター選びなど、ほかの画面にも効いてしまう）。
- `position: relative; top: -Npx` や負の `margin` など、数字で位置をずらす直し方はしない（文字の大きさの設定が変わると、またずれる）。
- 既存の CSS の書き方に合わせる（字下げは空白 2 つ、1 行に 1 つの宣言、色や大きさの書き方）。
- 変えてはいけないファイル: `package.json`、`package-lock.json`、`tools/`、`.github/`、`.gitignore`、`.gitattributes`、`CLAUDE.md`、`AGENTS.md`。
- `git` の操作をしない。パッケージを足さない。このフォルダの外を見ない・変えない。
- テストのファイル（`tests/`）は変えない。足さない（下の「テストと完了の条件」）。

## 端の場合

### 不正な入力

- この変更は見た目（CSS）だけで、入力を受け取らない。ニックネームの検証（長さ・空など）は、いまのまま変えない。
- プロフィールを選んでいないとき（`updateHeader()` が中身を空にしたとき）: `#header-profile` は空の flex の箱になり、幅も高さも 0。いまと同じく、帯には何も出ない。帯の高さも変わらない（`.header-inner` の `min-height: 56px` で決まる）。
- `RQ.ui.helpers` がなくてアバターが入らないとき: ニックネームの `span` だけが入る。flex の子が 1 つなので `gap` は効かず、ニックネームだけが右寄せで出る。

### 重複と境界

- ニックネームがいちばん長いとき（12 文字）と、せまい画面（幅 320px）: `.header-inner` は `flex-wrap: wrap` なので、アプリ名と同じ行に入らなければ、プロフィールは次の行に折り返す。折り返したあとも `margin-left: auto` で右に寄る。`min-width: 0` があるので、それでも入らないときはニックネームが箱の中で折り返し、帯の外にはみ出さない。アバターは `.avatar` の `flex: none` でつぶれない。
- ニックネームが 1 文字のとき: アバターとニックネームが、間隔 6px で上下の中央にそろう。
- 文字の大きさの設定を変えたとき（設定画面の文字の大きさ）: 数字で位置をずらしていないので、どの大きさでも中央にそろう。
- ふりがなを出す設定のとき: ニックネームは `data-no-ruby` なので、ふりがなは付かない。いまと同じ。

### 失敗の見せ方

- この変更は、エラーや違反を出す場面を足さない・変えない。保存の状態（`#save-status`）と教材エラーの件数（`#content-error`）の出し方は、いまのまま。
- 見た目がくずれた場合に気づけるよう、下の「ブラウザでの確認」を必ず行い、結果を報告に書く。くずれを見つけたら、黙って別の直し方に変えず、見つけた画面・幅・ようすを報告に書く。

## テストと完了の条件

### 自動テスト

- テストは足さない・変えない。理由: テストは DOM の代わりの部品で動いていて、CSS の配置は調べられない。`tests/link.test.js:553` は `header-profile` の id を使うだけなので、この変更の影響を受けない。
- `npm test` がすべて成功すること（変える前と同じ件数が通ること）。

### ブラウザでの確認（できる場合）

確認用の道具や一時スクリプトは、このフォルダの中に置かない。ブラウザで確かめられない場合は、「ブラウザでは確かめていない」と報告にはっきり書く。

1. ホーム画面: 上の帯で、ニックネームの文字の上下の中央が、アバターの丸の中央とそろっている。
2. ホーム以外の画面（単元の一覧、問題、設定など）でも、帯の見え方が同じ。
3. アバターとニックネームの間隔が、変える前とほぼ同じ（くっついていない・離れすぎていない）。
4. 12 文字のニックネームで、幅 320px と 720px 以上の両方を見る。帯の外にはみ出さない。右寄せのまま。保存の状態（`#save-status`）と重ならない。
5. プロフィールを選ぶ前の画面: 帯にプロフィールが出ず、帯の高さが変わらない。
6. プロフィール一覧・アバター選び・先生の画面のアバターの見え方が、変える前と同じ（`.avatar` を変えていないことの確かめ）。

### 完了の条件

- `css/style.css` の `.header-profile` が、上の「変えたあと」のとおりになっている。
- ほかのファイルと、`css/style.css` のほかの規則に変更がない。
- `npm test` がすべて成功する。
- 報告に、変えたファイル、`npm test` の結果、ブラウザでの確認の結果（または確かめていないこと）を書く。
