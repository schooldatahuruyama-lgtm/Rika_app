# 実装指示書: バッジの絵を画像に差しかえる

作成: Claude Code（Fable）2026-11-06。実装: Opus。レビュー: Codex。ユーザー決定: スタイル B（光沢のある盾）。

## 目的

バッジ（`js/badges.js` の 20 個）の表示を、文字入りの簡易メダル（SVG）から、ChatGPT で生成した画像 `assets/images/badges/<id>.png`（160×160、白背景）に替える。取っていないバッジは同じ画像を灰色（CSS）で見せる。

## 前提

controller が `assets/images/badges/<id>.png` を 20 枚置いてある（`js/badges.js` の DEFS の id と同じ名前）。足りない id があれば、その id だけ今の SVG メダルのままにして報告に書く。

## 変更するファイル

| ファイル | 変更 |
|---|---|
| `js/ui-screens.js` | `badgeMedal(def, earnedState, size)` を画像に。`el('img', { class: 'badge-img', src: 'assets/images/badges/' + def.id + '.png', alt: '', width: size, height: size, draggable: false })` を今の `span.badge-medal`（role=img、aria-label、data-no-ruby はそのまま）に入れる。`size` は省略時 44。結果画面の「新しいバッジ！」は 64、ホームの最近 3 つと記録画面の一覧は 44。画像の読み込みに失敗したら（`onerror`）、今の SVG メダルに置きかえる（SVG を作る関数は `badgeMedalSvg(def)` として残す） |
| `css/style.css` | `.badge-img`（`display:block`、角を少し丸める `border-radius: 8px` は不要、`object-fit: contain`）、`.badge-medal.is-locked .badge-img { filter: grayscale(1); opacity: .45 }`。`.badge-medal` の背景の丸があれば画像では消す（画像自体が盾の形なので、丸い下地は付けない） |
| `sw.js` | `PRECACHE` に 20 枚（`assets/images/badges/<id>.png`、DEFS の順）。`VERSION` を `2026-11-06-23` に |
| `tests/badges.test.js` | DEFS の各 id について、`assets/images/badges/<id>.png` が存在し（`fs.existsSync`）、`sw.js` の PRECACHE にその文字列があることを検査 |
| `README.md` | バッジの節に「絵は ChatGPT で生成した画像（assets/images/badges/）」と一文 |

## 守ること

- 画像の alt は空（名前は親の aria-label が持つ）。文字は textContent。`data-no-ruby` を外さない。
- 画像ファイルは変えない・増やさない。`js/badges.js` の DEFS は変えない。
- `git add`・`git commit` はしない。内蔵ブラウザのタブは使わない（headless Edge か別ポートの http.server）。サブエージェントを起動しない。`npm test` 全件成功。
