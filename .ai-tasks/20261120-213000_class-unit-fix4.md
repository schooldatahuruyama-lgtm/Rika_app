# 実装指示書（修正 4）: 新しい部品（`js/class-unit.js`）が読みこまれていないときに、止まらないようにする

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。もとの指示書は `.ai-tasks/20261120-190000_class-unit.md`。

## 目的

公開後の確認（2026-11-20）で見つけた不具合。新しい版に入れかわる途中、オフライン用の保存（Service Worker）の古い `index.html`（`js/class-unit.js` を読みこまない）と、新しい `js/app.js` がまざって読みこまれることがある。そのとき `RQ.classUnit` が無く、`finishAccount` の中で次のエラーになり、アカウントのモードに入る処理が途中で止まる。

```
TypeError: Cannot read properties of undefined (reading 'createClassUnit')
    at finishAccount (js/app.js)
```

開き直すと新しい版にそろって直るが、止まらないようにする。

## 変える内容

### 1. `js/app.js`

- `RQ.classUnit` が無い、または `RQ.classUnit.createClassUnit` が関数でないときは、`state.classUnit = null` にして、そのまま先へ進む（単元の読みこみをしないだけで、アカウントのモード・記録の送り受けは今までどおり動く）。`loadClassUnit()` は、今でも `state.classUnit` が無ければ何もしないので、そのままでよい。
- `createClassUnit(...)` の呼び出しが例外を投げたときも、同じく `state.classUnit = null` にして先へ進む。
- ほかに、`RQ.classUnit` を、あるものとして直接使っている所があれば、同じように守る。
- 帯・画面・記録の送り受けの動きは変えない。

### 2. `sw.js`

- `VERSION` を `'2026-11-20-02'` にする（プログラムを変えたので）。`PRECACHE` は変えない。

## 端の場合

- 不正な入力: `RQ.classUnit` が `undefined`・`null`・関数を持たないオブジェクト → 単元の読みこみをしない。エラーを出さない。
- 重複と境界: 部品が無いまま学習して保存 → 記録の送り受けはふつうに動く。次に開いて部品がそろえば、単元の読みこみが始まる。
- 違反や失敗の見せ方: 何も出さない（次に開いたときに、先生の単元が当たる）。

## テスト

- `tests/link.test.js`（アプリ全体）: `RikaQuest.classUnit` が無い状態でアカウントのモードに入る → 例外・`console` のエラーが出ず、ホーム（またはプロフィールの画面）まで進み、記録の送り受け（`rika/state` の読みこみ）が行われ、`accounts/`・`memberOf/`・`rika/classUnit/` は読まれない。
- `createClassUnit` が投げる場合も同じ。
- `tests/offline.test.js` が通ること。`npm test` がすべて成功すること。
