## B との違い

- **`anim` が付いているカードは画像にしない**（sound・electricity・motion の解説カードは動く図が付いているものが多い。付いていないカードだけ差しかえる。付いているものは報告に「動く図があるので見送り」と書く）。
- **問題（figure-choice）**: 写真の上に `region`（ア・イ・ウ、r 22 以上、互いに 48px 以上はなす）を置き、`answer` の region id はそのまま。問題文のア・イ・ウの説明が写真の位置と合うように、必要なら問題文も直す。`samples` のない形式なので判定は変わらない。元の簡略図の `region` の座標に合わせる必要はない（写真に合わせる）。
- light の lens-2-c3 は公開済みの単元なので、文字・座標を慎重に（既存の `anim` があれば見送り）。
- `sw.js`・`js/*`・`index.html`・テストは触らない（PRECACHE は controller が足す）。写真用の部品名は `photo`・`pointer`・`tag`。
- 報告は `.ai-tasks/20261105-050000_画像の組みこみC_<単元>_result.md`。
