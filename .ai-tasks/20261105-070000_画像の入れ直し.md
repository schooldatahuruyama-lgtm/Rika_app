# 実装指示書: 作り直した画像の入れ直し

作成: Claude Code（Fable）2026-11-05。実装: Opus（分野ごとに分担）。一覧: `docs/image-redo.md`（合格した画像だけが対象。不合格のものは `gen_images/log.md` に「不合格」とある）。手順は A/B/C の指示書（`.ai-tasks/20261104-224000_画像の組みこみA.md`、`20261105-030000_画像の組みこみB.md`、`20261105-050000_画像の組みこみC.md`）と同じ。

## やること

1. controller が `assets/images/<単元>/<id>.jpg`（640×480）を上書きしてある。**必ず新しい画像を Read で見て**、そのカードの文字・引き出し線・区切り線の座標を写真に合わせて直す（前の座標のままにしない）。
2. いままで簡略図のまま残していた 2 枚（ion-2-c1: 塩化銅の電気分解、sol-4-c4: ろ過）は、合格していれば新しく写真＋文字に差しかえる（`photo`・`pointer`・`tag`。文字は 13px 以上・白い下地・右はしは `anchor: 'end'`）。ion-2-c1 は「陰極（−）: 銅が付く」「陽極（＋）: 塩素が出る」を導線の色（黒・赤）と合わせて示す。
3. refract-2-c2（light）は `anim` が付いていないカードなら差しかえ、付いていれば見送って報告に書く。
4. headless Edge で描いて目で確かめ、`npm test` を全件成功させる（`sw.js` は controller が整える。PRECACHE の失敗だけ許容）。
5. `docs/reports/content/<単元>.md` の該当カードが「（写真）」になっていることを確かめる。
6. 報告 `.ai-tasks/20261105-070000_画像の入れ直し_<分野>_result.md`（直したカード、見送ったカードと理由、テスト）。返事は 150 字程度。

## 守ること

- 変えてよいのは担当の単元の `content/<単元>.js` と `docs/reports/content/<単元>.md` だけ。`sw.js`・`js/*`・`index.html`・テストは触らない。git 操作なし。内蔵ブラウザのタブは使わない。サブエージェントなし。
