# 理科クエスト（試作1）

中学校理科の e-learning Web アプリの試作です。生徒がブラウザで問題に取り組み、学習の記録が手元（その端末のブラウザ）に残ります。

- 試作1 の教材は「光の世界」の 4 領域 × 2 ステージ = 8 ステージ（光の直進 → 反射 → 屈折 → 凸レンズ）。
- 問題は 5 形式: 選択式、穴埋め、図の場所を選ぶ、光線を引く、光学要素（物体・スクリーンなど）を動かす。
- 生徒は架空の生徒（ニックネームとアバター）だけを使います。実名は入れません。
- インストール不要、外部ライブラリなし（HTML・CSS・JavaScript だけ）。Chrome または Edge で使います。

## 開き方

- **かんたんに開く:** `index.html` をダブルクリックして Chrome または Edge で開く。ネット接続もサーバーも不要です。ただしこの開き方（`file://`）ではオフライン対応は効きません（アプリ自体はそのまま使えます）。
- **オフライン対応つきで開く:** このフォルダで次を実行し、Chrome または Edge で http://127.0.0.1:8765/ を開く。
  ```
  python -m http.server 8765 --bind 127.0.0.1
  ```
  Service Worker は https または localhost（127.0.0.1）でだけ動くため、同じパソコンで http://127.0.0.1 として開いたときにオフライン対応が効きます。ほかの端末から LAN の IP を http で開いた場合、アプリは使えますがオフライン対応は効きません。

## はじめての流れ

1. **プロフィールを作る:** ニックネーム（12 文字まで、実名は入れない）とアバターを選んで「プロフィールを作る」。先生が複数の生徒を演じられるよう、何人でも作って設定画面で切り替えられます。
2. **ホーム:** 「今日のクエスト」「レベルと経験値」「連続学習」のカードと、「学習マップへ」「記録を見る」「設定」のボタン。
3. **学習マップ:** 領域とステージを選ぶ → ステージ入口で「解説から学ぶ」か「問題から挑戦」を選ぶ。

## 記録について（大事）

- 記録はその端末のブラウザ（localStorage）だけに保存されます。ブラウザのデータ削除や端末の変更で**消えることがあります**。
- 設定画面の「記録を書き出す」で JSON ファイル（`rika-quest-*.json`）にバックアップでき、「記録を読み込む」で元に戻せます。
- 書き出したファイルには学習記録が入るので、Git には入れない設定にしてあります。

## 試作品の検証項目の確かめ方

要件定義書の「試作品の検証項目」1〜6 を、次の手順で確かめられます。タブレット・スマホ幅は、Chrome/Edge の開発者ツール（F12）のデバイス表示で幅 768px と 375px にして見ます。

1. **学習マップで進める:** ホーム →「学習マップへ」。4 領域が縦の道に並び、どの領域の 1 つ目のステージからでも始められる。1 つ目をクリアすると 2 つ目が開き、ステージに状態（未着手・途中・クリア）と星（0〜3）が付く。
2. **解説から／問題から始める:** ステージ入口で「解説から学ぶ」（解説カード 3 枚 → 予想 1 問 → 問題）と「問題から挑戦」（すぐ問題）の両方を試す。問題の途中でも「解説を見る」で解説を開ける。
3. **5 形式の操作:** 「光はまっすぐ進む」（直進 1）に選択式・穴埋め・図の場所を選ぶ・物体を動かす、「反射の法則」（反射 1）と「屈折の向き」（屈折 1）に光線を引く、「焦点と光の集まり方」（凸レンズ 1）に光線を引く・スクリーンを動かすがある。指（マウス）でなぞる・動かす・タップして選ぶを確かめる。
4. **誤答 → 類題 → 学び直し → 復帰:** 反射 1 をクリアしてから「鏡に映る像」（反射 2）で 1 問目をわざと間違える →「おしい」と解説 → 同じ内容の類題が出る → また間違える →「反射の法則に戻って確かめよう」が出る。「戻る」で確認問題 2 問 → 正解すると元のステージの続きに戻る。「あとで」を選ぶと続きに進み、結果画面に「〜を確かめるのがおすすめ」と出る。
5. **正解率以外の取り組みが経験値になる:** 結果画面の「獲得した経験値」に内訳（答えた、正解、1 回目で正解、復習で正解、学び直し、解説を読んだ、ステージクリア、今日の学習）が出る。間違えても「答えた」「復習で正解」などで経験値が入ることを確かめる。記録画面には理解度の目安（まだ / もう少し / できた）が経験値とは別のカードで出る。
6. **オフラインで使い続けられる:** 上の「オフライン対応つきで開く」で一度開き、設定画面の「オフラインで使える教材」が「済」になるのを確かめる。サーバーを止めて（コマンドの画面で Ctrl+C）ページを再読み込みしても学習を続けられ、答えた記録が残る（サーバーを再開して開き直しても残っている）。

## オフライン対応のしくみ

- Service Worker は https または localhost（127.0.0.1）でだけ動きます。LAN の IP（例: `http://192.168.x.x:8765/`）を http で開いたときや `file://` では、オフライン対応は使えません（アプリ自体はそのまま使えます）。
- https か http://127.0.0.1 で開いたときだけ、Service Worker（`sw.js`）がアプリ本体（HTML・CSS・JS）と教材（光の世界）をこの端末のブラウザに保存します。その後は通信がなくても、同じ URL を開けば学習を続けられます。
- 何を保存するかは `sw.js` の `PRECACHE` に書いてあります。`index.html` に読み込むファイルを足したら、ここにも足してください（`npm test` が食い違いを見つけます）。

### 教材やプログラムを更新したとき

- 教材やプログラムを更新したら `sw.js` の `VERSION` を上げる（例: `2026-11-04-7` → `2026-11-04-8`）。
- 次にオンラインで開いたときに新しい版に入れ替わり（古い保存は消える）、もう一度開き直すと新しい版で動きます。記録（localStorage）は残ります。
- `VERSION` を上げ忘れると、ブラウザは古い版を使い続けます。

## 教材の内容について

教材の文章・図・問題はすべて自作です（教科書名・出版社名は書いていません）。理科としての正しさ（用語、図の角度、正解・解説の内容）は、**授業で使う前に先生が確認してください**。教材は `content/light.js` にまとまっています。
