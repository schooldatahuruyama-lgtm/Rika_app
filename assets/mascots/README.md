# マスコット画像

ユーザーが用意した Google ドライブのフォルダ「理科Webアプリ_マスコット_A-F」（2026-11-04）の `svg/mascot_A.svg`〜`mascot_F.svg` です。
アプリ用に viewBox を背景の丸（半径 175）にぴったり合わせ、350×350 にしています（絵の中身は変えていません）。

単元ごとに担当の先生が変わります。教材の単元（`content/*.js` の `unit`）に `mascot: 'E'` のように書くと、その先生がホーム・結果・レベルアップの祝いに出ます（対応表は `js/mascot.js` の `MASCOTS`）。書いていない単元は まる先生（A）です。いまは「光の世界」がキューブ先生（E）です。

| ファイル | 名前 | 担当（同梱の unit_mascots.json より） |
|---|---|---|
| mascot_A.svg | まる先生 | 汎用・ホーム・ヘルプ |
| mascot_B.svg | しずく博士 | 水溶液・状態変化 |
| mascot_C.svg | ぷにカプセル | 物質・化学変化・イオン |
| mascot_D.svg | もくもく先生 | 天気・地学・地球と宇宙 |
| mascot_E.svg | キューブ先生 | 光・電流・運動・エネルギー |
| mascot_F.svg | まめ博士 | 生物・細胞・生命 |

生徒が選ぶアバター（`assets/avatars/`）は別の画像です。
