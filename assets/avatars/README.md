# アバター画像

ユーザーが用意した Google ドライブのフォルダ「理科Webアプリ_マスコット_A-F」（2026-11-04）の `svg/mascot_A.svg`〜`mascot_F.svg` をもとにしています。
アプリ用には viewBox を背景の丸（半径 175）にぴったり合わせ、350×350 にしています（絵の中身は変えていません）。

| ファイル | 名前 | 元の用途 | 保存済みプロフィールの ID |
|---|---|---|---|
| mascot_A.svg | まる先生 | 汎用・ホーム・ヘルプ | `fox` |
| mascot_B.svg | しずく博士 | 水溶液・状態変化 | `cat` |
| mascot_C.svg | ぷにカプセル | 物質・化学変化・イオン | `dog` |
| mascot_D.svg | もくもく先生 | 天気・地学・地球と宇宙 | `panda` |
| mascot_E.svg | キューブ先生 | 物理・電流・運動・エネルギー | `frog` |
| mascot_F.svg | まめ博士 | 生物・細胞・生命 | `penguin` |

ID を従来の値のままにしているのは、生徒がすでに保存したプロフィールの `avatar` をそのまま使うためです。
