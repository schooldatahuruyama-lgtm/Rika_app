# 教材の内容一覧「火山と地震」（先生の確認用）

原本は `content/volcano.js`（中学 1 年 地学、担当 もくもく先生）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `volcano` 火山（order 1: volcano-1・volcano-2）、`quake` 地震（order 2: volcano-3・volcano-4）
- 概念 6 つ: `vo-magma` マグマと火山の形（basic null、解説 volcano-1）、`vo-igneous` 火山岩と深成岩（basic vo-magma、解説 volcano-2）、`vo-mineral` 鉱物（basic vo-igneous、解説 volcano-2）、`vo-wave` P波・S波と初期微動継続時間（basic null、解説 volcano-3）、`vo-scale` 震度とマグニチュード（basic vo-wave、解説 volcano-4）、`vo-plate` プレートと地震（basic vo-scale、解説 volcano-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
