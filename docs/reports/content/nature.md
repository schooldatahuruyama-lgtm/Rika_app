# 教材の内容一覧「自然と人間」（先生の確認用）

原本は `content/nature.js`。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作（ミニプリントは出題のねらい・用語・生物の例の参考にしただけ）。

- 単元 `nature`「自然と人間」（中学 3 年 生物、担当の先生 A まる先生）
- 領域 2: `na-ecosystem`「生態系」(order 1)、`na-human`「人間と環境」(order 2)
- ステージ 4、概念 4、問題 56 問（ステージの warmup・problems・retryPool 44 問 ＋ 確認問題 12 問）
- 概念 id は単元の接頭辞 `na-` 付き（`na-foodchain`・`na-decomposer`・`na-environment`・`na-energy`）

形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。用語問題（`term: true`）は id が `-t`。

## nature-2「分解者と物質の循環」（5 分、概念 na-decomposer）
