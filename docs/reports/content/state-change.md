# 教材の内容一覧「状態変化」（先生の確認用）

原本は `content/state-change.js`（中学 1 年 化学、担当 しずく博士）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `state` 状態変化と粒子（order 1: state-1・state-2）、`sc-distill` 混合物を分ける（order 2: state-3・state-4）
- 2026-11-21 追加: 領域 `state-change-drill`「ドリル」（order 4、ステージ 1。練習プリントのテーマに合わせた自作の問題。末尾の「ドリル」の節）
- 2026-11-21: 領域を分野でまとめ、プリント・ドリルは free のステージ（いつでも挑戦できる）として各分野に入れた（状態変化と粒子: state-1・state-2・state-change-mp1・state-change-mp2・state-change-dr1 ／ 混合物を分ける: state-3・state-4・state-change-mp3・state-change-mp4）。
- 2026-11-22 追加: クイズ 1 ステージ（free。状態変化と粒子: state-change-kq1。公開クイズのねらいを参考にした自作の問題。末尾の「クイズ」の節）
- 概念 5 つ: `sc-change` 状態変化と質量・体積（basic null、解説 state-1）、`sc-model` 粒子のモデル（basic sc-change、解説 state-1）、`sc-point` 融点・沸点とグラフ（basic sc-change、解説 state-2）、`sc-mixture` 純粋な物質と混合物（basic sc-point、解説 state-3）、`sc-distill` 蒸留（basic sc-mixture、解説 state-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。

参考: Kahoot『中学理科　一年　物質の状態変化～状態変化と質量・体積～』『中学理科　１年　物質の状態変化　〜要点チェック〜』

カード: c1 状態変化で質量は変わらないので、体積が小さくなると密度は大きくなります。多くの物質は固体のほうが液体より密度が大きく、液体の中に固体を入れると沈みます。水は例外で、氷は水に浮きます。／c2 加熱すると粒子の運動が激しくなり、粒子どうしの間隔が広がります。粒子の数は変わりません。固体→液体→気体の向きの変化は加熱で、その逆向きの変化は冷却で起こります。

- state-change-kq1-p3: 水 90 g が氷 98 cm³ になる、とした（密度 約 0.92 g/cm³）。答えは小数第 1 位まで 0.9（許容 0）。
