# 教材の内容一覧「水溶液」（先生の確認用）

原本は `content/solution.js`（中学 1 年 化学、担当 しずく博士）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `dissolve` 水にとける（order 1: sol-1・sol-2）、`sol-solubility` 溶解度（order 2: sol-3・sol-4）
- 概念 5 つ: `sol-terms` 溶質・溶媒・溶液（basic null、解説 sol-1）、`sol-particle` 粒子のモデルと水溶液の性質（basic sol-terms、解説 sol-1）、`sol-concentration` 質量パーセント濃度（basic sol-terms、解説 sol-2）、`sol-solubility` 溶解度と飽和水溶液（basic sol-particle、解説 sol-3）、`sol-recrystal` 再結晶と取り出し方（basic sol-solubility、解説 sol-4）
- 問題 58 問（ステージの warmup・problems・retryPool 43 問 ＋ 確認問題 15 問）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
- 図の溶解度曲線は目安の値でかいた（水 100 g あたり）: 硝酸カリウム 0℃ 13 g・10℃ 22 g・20℃ 32 g・30℃ 46 g・40℃ 64 g・50℃ 85 g・60℃ 110 g、塩化ナトリウム 約 36〜37 g（ほぼ横ばい）。ミョウバンの曲線はかいていない。
