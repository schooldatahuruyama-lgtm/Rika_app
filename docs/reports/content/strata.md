# 教材の内容一覧「地層と大地の変化」（先生の確認用）

原本は `content/strata.js`（中学 1 年 地学、担当 もくもく先生）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `form` 地層のでき方（order 1: strata-1・strata-2）、`history` 地層から読み取る（order 2: strata-3・strata-4）
- 概念 6 つ: `st-erosion` 風化・侵食・運搬・堆積（basic null、解説 strata-1）、`st-grain` 粒の大きさと堆積する場所（basic st-erosion、解説 strata-1）、`st-sedimentary` 堆積岩の種類（basic st-grain、解説 strata-2）、`st-fossil` 示相化石と示準化石（basic null、解説 strata-3）、`st-column` 柱状図とかぎ層（basic st-sedimentary、解説 strata-4）、`st-deform` しゅう曲・断層・隆起（basic st-column、解説 strata-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
