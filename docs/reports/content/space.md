# 教材の内容一覧「地球と宇宙」（先生の確認用）

原本は `content/space.js`（中学 3 年 地学、担当 もくもく先生）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `sp-earth` 地球の動きと天体の見え方（order 1: space-1・space-2）、`sp-solar` 太陽系（order 2: space-3・space-4）
- 概念 6 つ: `sp-rotation` 地球の自転と日周運動（basic null、解説 space-1）、`sp-hemisphere` 透明半球と南中高度（basic sp-rotation、解説 space-1）、`sp-revolution` 地球の公転と年周運動（basic sp-rotation、解説 space-2）、`sp-season` 季節の変化と南中高度（basic sp-revolution、解説 space-2）、`sp-moon` 月の満ち欠けと日食・月食（basic sp-revolution、解説 space-3）、`sp-sun` 太陽と太陽系・金星の見え方（basic sp-moon、解説 space-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
- 図の決まり: 地球・月・金星の公転の図は北極側（真上）から見た図で、自転・公転はどれも反時計回り。月の図は太陽の光が左から、金星の図は太陽が上・地球が下。透明半球は北側から南を向いて見下ろした図（東が左、西が右）で、太陽の通り道は北緯 35° として計算した。南中高度は北緯 35°（春分・秋分 55°、夏至 78.4°、冬至 31.6°、地軸の傾き 23.4°）。
- 読み取りの問題の図には答えを書いていない（季節の名前、月の形の名前、南中高度の数値、金星の名前は問題の図にない）。
