# 教材の内容一覧「動物のなかま」（先生の確認用）

原本は `content/animals.js`。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作（ミニプリントは出題のねらい・用語・動物の例の参考にしただけ）。

- 単元 `animals`「動物のなかま」（中学 1 年 生物、担当の先生 F まめ博士）
- 領域 2: `vertebrate`「セキツイ動物」(order 1)、`invertebrate`「無セキツイ動物」(order 2)
- ステージ 4、概念 5、問題 59 問（ステージの warmup・problems・retryPool 44 問 ＋ 確認問題 15 問）
- 概念 id は単元の接頭辞 `an-` 付き（`an-groups`・`an-traits`・`an-arthropod`・`an-mollusc`・`an-classify`）

形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。用語問題（`term: true`）は id が `-t`。

## animals-4「動物の分類をまとめる」（5 分、概念 an-classify）

参考: セキツイ動物の分類まとめ　Ａ４.docx（特徴の組み合わせでなかまを決める）、セキツイ動物と無セキツイ動物　Ａ４.docx（背骨の有無で分ける）。肉食動物・草食動物はミニプリントになかったので、教科書の標準的な範囲で補った。

カード: c1 分類はまず背骨の有無。セキツイ動物は生まれ方・呼吸・体温など、無セキツイ動物は外骨格・外とう膜など（動物の分類の全体図）／c2 胎生 → ホニュウ類、卵生・殻あり → 体温一定は鳥類・変わるはハチュウ類、卵生・殻なし → 一生えらは魚類・親は肺は両生類（枝分かれ図）／c3 肉食動物は目が前向き（立体的に見える範囲が広く距離をつかみやすい）、草食動物は目が横向き（広い範囲を見わたせる）（写真）／c4 肉食動物の犬歯・とがった臼歯、草食動物の門歯・平らな臼歯（写真）
