# 教材の内容一覧「化学変化とイオン」（先生の確認用）

原本は `content/ion.js`（中学 3 年 化学、担当 ぷにカプセル）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `io-ion` 水溶液とイオン（order 1: ion-1・ion-2）、`io-acid` 酸・アルカリと中和（order 2: ion-3・ion-4）
- 概念 6 つ: `io-electrolyte` 電解質と電離（basic null、解説 ion-1）、`io-structure` 原子の構造とイオン（basic null、解説 ion-1）、`io-electrolysis` 電気分解（塩化銅水溶液・塩酸）（basic io-electrolyte、解説 ion-2）、`io-battery` イオンへのなりやすさと電池（basic io-structure、解説 ion-2）、`io-acidbase` 酸・アルカリと指示薬・pH（basic io-electrolyte、解説 ion-3）、`io-neutral` 中和と塩（basic io-acidbase、解説 ion-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
- イオン式は上付き文字が使えないので「Na+」「Cl-」「Cu2+」「OH-」のように書いた（下付きの H₂O・CuCl₂ はそのまま）。
- イオンのモデルの色: H+ 桃、Na+ 黄、Cu2+ うすい茶、Zn2+ 灰、Cl- うすい緑、OH- 水色。
- drag の座標は図（320×240）の中の位置。許容は 16px。
