# 教材の内容一覧「身のまわりの物質」（先生の確認用）

原本は `content/substance.js`（中学 1 年 化学、担当 ぷにカプセル）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `props` 物質の性質（order 1: sub-1・sub-2）、`gas` 気体の性質（order 2: sub-3・sub-4）
- 概念 6 つ: `su-metal` 金属の性質（basic null、解説 sub-1）、`su-organic` 有機物と無機物（basic null、解説 sub-1）、`su-density` 密度と計算（basic null、解説 sub-2）、`su-measure` メスシリンダーと上皿てんびん（basic null、解説 sub-2）、`su-collection` 気体の集め方（basic null、解説 sub-3）、`su-gases` 気体の性質と発生（basic su-collection、解説 sub-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
