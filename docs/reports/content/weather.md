# 教材の内容一覧「天気とその変化」（先生の確認用）

原本は `content/weather.js`（中学 2 年 地学、担当 もくもく先生）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `air` 大気と水蒸気（order 1: weather-1・weather-2）、`front` 前線と天気の変化（order 2: weather-3・weather-4）
- 概念 7 つ: `we-pressure` 圧力と大気圧（basic null、解説 weather-1）、`we-observe` 天気記号と風向（basic null、解説 weather-1）、`we-humidity` 飽和水蒸気量・露点・湿度（basic null、解説 weather-2）、`we-cloud` 雲のでき方（basic we-humidity、解説 weather-2）、`we-system` 高気圧と低気圧（basic we-pressure、解説 weather-3）、`we-front` 前線の種類と通過（basic we-system、解説 weather-3）、`we-japan` 日本の四季の天気（basic we-front、解説 weather-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
- 飽和水蒸気量のグラフの値: 0 ℃ 4.8、5 ℃ 6.8、10 ℃ 9.4、15 ℃ 12.8、20 ℃ 17.3、25 ℃ 23.1、30 ℃ 30.4 g/m³（ミニプリントの表と同じ。0 ℃ はミニプリントの 4.9 ではなく 4.8 にした）。読み取りの問題の図には、答えの数値を書いていない（目盛りは 0・10・20・30、補助線は 5 ごと）。
