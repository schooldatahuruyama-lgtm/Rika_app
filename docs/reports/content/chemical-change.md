# 教材の内容一覧「化学変化と原子・分子」（先生の確認用）

原本は `content/chemical-change.js`（中学 2 年 化学、担当 ぷにカプセル）。理科としての正しさは先生が確認する（設計書 10）。文章・図はすべて自作で、ミニプリントは出題のねらい・用語・数値の例の参考にだけ使った。

- 領域 2 つ: `atom` 物質のなりたち（order 1: chem-1・chem-2）、`reaction` 化学変化と質量（order 2: chem-3・chem-4）
- 概念 6 つ: `ch-decomposition` 分解（熱分解・電気分解）（basic null、解説 chem-1）、`ch-atom` 原子と元素記号（basic null、解説 chem-2）、`ch-formula` 分子と化学式・単体と化合物（basic ch-atom、解説 chem-2）、`ch-equation` 化学反応式と物質が結びつく変化（basic ch-formula、解説 chem-3）、`ch-oxidation` 酸化・燃焼・還元（basic ch-equation、解説 chem-3）、`ch-conservation` 質量保存の法則と質量の比（反応と熱をふくむ）（basic ch-oxidation、解説 chem-4）
- 形式の略: C = choice、F = fill、FC = figure-choice、D = drag。正解を【】で示す。「用語」は term: true の用語問題。
- 原子のモデルの色: 水素 白、酸素 水色、炭素 灰色、銅 茶色（ほかに 窒素 うすい緑、硫黄 黄、鉄 岩の色、ナトリウム 紫、塩素 緑、マグネシウム・銀 ガラス色）。
