作成: 2026-11-05（実装担当の AI がまとめたもの）。開発中に実装担当が「理科として自信がない」「先生に確かめてほしい」と書いた所、AI で作った写真、動く図を、単元ごとに 1 枚にまとめました。

- **公開版**（タブレットで開く）: https://schooldatahuruyama-lgtm.github.io/Rika_app/ 。単元を開き、解説カードと問題を見ながら確かめてください。
- **単元ごとの一覧表**: `docs/reports/content/<単元 id>.md`（カードの文と、全問題の正解）。光の世界だけは一覧表がなく、原本は `content/light.js` です。
- **確認の観点は 3 つ**: ① 内容の正しさ（用語・数値・法則・分類・実験の手順と安全）／② 写真が説明と合っているか・写真の上の文字が読めるか／③ 動く図の動きが理科として正しいか。
- **場所の書き方**: 「force-1 c2」はステージ force-1 の解説カード 2 枚目、「force-4-p1」「mass-k1」などは問題の id（一覧表の id と同じ）。
- 各項目の「〜とした」は、いまの教材の書き方です。そのままでよければ □ にチェックを入れてください（Obsidian で押せます）。
- **気づいたことの伝え方**: チャットで「単元名 ＋ カード番号（c1 など）か問題 id ＋ 何が違うか（どう直すか）」をお知らせください。例:「力のはたらき force-4-p1 の解説、『回る』は消してよい」。
