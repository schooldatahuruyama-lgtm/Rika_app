## 3. 実装の形

### 3-1. 登録口を足す（js/anim.js）

いまの `anim.js` は光の 23 種を `BUILD` に直接書いている。光の部分はそのままにし、分野ごとのファイルから足せる登録口を作る。

```js
// kind の動く図を足す。frameFn(t) は item の配列を返す純粋関数（光の BUILD の関数と同じ形）
// opts.restT: 止まっているときに見せる位置（既定 0）。opts.period: 1 周の時間 ms（既定 PERIOD_MS = 4000）
anim.register(kind, frameFn, opts)
```

- `kind` は英小文字・数字・ハイフンだけ（`/^[a-z]+(-[a-z0-9]+)*$/`）。すでにある kind（光の 23 種をふくむ）と同じ名前、関数でない `frameFn`、`restT` が 0 以上 1 未満でない、`period` が正の数でない、はどれも例外。
- 登録すると `KINDS` の配列の後ろに足す（`ui-screens.js` の `lessonFigure` は `anim.KINDS.includes(card.anim)` で見ているので、画面側は変えなくてよい）。`KINDS` の先頭 23 個は今の光の順のまま。
- `frame(kind, t)` は `BUILD` → 登録したもの の順で探す。知らない kind は今と同じく例外。返す形は今と同じ `{ width: 320, height: 240, items }`。
- `restT(kind)` は光の `REST_AT_END` → 登録の `opts.restT` → 0。
- 周期: `create(kind)` の中の `PERIOD_MS` を `periodOf(kind)`（登録の `opts.period`、なければ 4000）に替える。天体の 1 周（月の公転・季節・地球の公転）は 8000、それ以外は 4000 を目安にする（各 kind の欄に書く）。
- `api` に `register` と `periodOf` を足す。`helpers` に下の道具を足す。

### 3-2. 共通の道具（anim.helpers）

今ある `clamp01`・`stage`・`lerp`・`grow`・`deg`・`rad2deg`・`u`・`N` に加えて、次を足す（光の関数は今のまま使う）。

| 名前 | 引数 → 戻り値 | 使いみち |
|---|---|---|
| `clamp(v, lo, hi)` | 数 → 数 | 今の内部関数を公開する |
| `ease(k)` | 0〜1 → 0〜1（`k*k*(3-2k)`） | 動き始めと止まりをなめらかに |
| `osc(t, n, phase)` | `sin(2π(n·t + phase))`。`n` は整数 | 振動。`n` が整数なので t = 1 で t = 0 とつながる |
| `tri(s)` | `1 - |2·frac(s) - 1|`（0→1→0 の三角波） | 気体の粒子が壁ではね返る動き |
| `wrap(v, lo, hi)` | `lo + frac((v - lo) / (hi - lo)) · (hi - lo)` | 前線・気圧・波面を横に流し、はしで反対側へ戻す |
| `pathLen(points)` | 折れ線 → 長さ | |
| `along(points, k)` | 折れ線・割合 0〜1 → `{ x, y, tx, ty }` | 点を道すじに沿って動かす（`weather.js` の `along` は長さで指定。こちらは割合） |
| `partial(points, k)` | 折れ線・割合 0〜1 → 点の配列（2 点以上、k = 0 なら `[]`） | 汎用の `line` を途中まで描く（グラフの線・神経の信号・電子の道） |
| `growLine(points, k, style)` | → `line` の item 1 つの配列（`partial` の点、`style` の color・width・dashed、`arrow: true`）。k = 0 なら `[]` | 光以外の「伸びる線」。光の `grow` は橙の `ray` なので使わない |
| `onCircle(cx, cy, r, d)` | 度 → `[x, y]`（右が 0°、画面で反時計回りが正。`content/space.js` と同じ） | 天体・回転 |
| `mix(c1, c2, k)` | `'#rrggbb'` 2 つ → `'#rrggbb'` | 石灰水のにごり・BTB の色・空気の温度の色 |
| `TOKEN_HEX` | トークン名 → `'#rrggbb'`（`figures-guide.md` の表） | `mix` にトークンの色を渡すとき |

道具の決まり:

- 周期の終わり（t → 1）と始まり（t = 0）がつながるようにする。振動・回転は整数回（`osc` の `n`）。一方向に進む動き（伸びる線・落下・移動）は「進む → 止まって見せる → t = 0 で始めにもどる」の形にし、止まって見せる時間を 0.1〜0.2 周とる（光の `stage(t, 0, 0.8)` と同じ）。
- 乱数は使わない（純粋関数・テストのため）。粒子のばらつきは `i` からつくる位相（例 `phase = (i * 0.37) % 1`）で出す。
- 座標は丸めない（表示の文字だけ `Math.round`。光と同じ）。

```js

(function (root) {
  'use strict';
  const anim = typeof require === 'function' ? require('./anim.js') : root.RikaQuest.anim;
  const { stage, lerp, u, osc, ease, growLine, along, onCircle, mix } = anim.helpers;

  // ---- 音の世界 ----

  const DEFS = [
    ['so-air-wave', soAirWave, { restT: 0 }],
    ...
  ];

  const api = { KINDS: DEFS.map(d => d[0]) };   // このファイルで足した kind（テスト用）
```

## 4. 各 kind に共通の決まり

- 場面は 320×240、座標は x 右向き・y 下向き。静止図と同じ部品は同じ座標・文字・色を使う。動く部品だけを式で動かす。
- 「止まった絵（restT）」は、静止図にいちばん近い位置にする。線が伸びていく kind は描き終わり（0.99）、量が行き来する kind は静止図と同じ値になる t。各 kind の欄に書く。
- 動きに合わせて変わる文字（「いま 2.4 N」「夕方」など）は、静止図の文字の空いた所に足す。静止図の文字の位置は動かさない（変えるときは「文字の例外」に書く）。
- 光線（橙の `ray`）は光の単元だけ。ほかの単元の矢印は `arrow`、伸びる線は `growLine`（`line`）。
- 粒子・イオン・原子の色は静止図と同じ（例: 酸素原子 `sky`、水素原子 `white`、Na+ `yellow`、Cl- `lightgreen`）。
- 点（電流の向き・炭素・信号）は半径 3〜5 の `circle`。文字を入れる丸は半径 10 以上。

### 5-1. sound（音の世界）— A 4・B 1

#### so-air-wave（sound-1-c3）A
- 動き: おんさの 2 本の腕（静止図の `rect` x 30・60）が `±3·osc(t, 8)` で左右にふるえる（腕の外の点線は今のまま）。空気の振動の波面（静止図の青い弧 4 本）が右へ進む。弧 k（k = 0〜3）の x = `wrap(110 + 40k + 160t, 110, 270)`、弧の半分の高さ = `35 + 0.25·(x − 110)`（55 まで）、ふくらみ = `10 + (x − 110)/12`。弧が x ≥ 262 に来たら耳の中の鼓膜（耳の楕円の中に縦の短い線 (284,105)–(284,125)）が `±2·osc(t, 8)` でふるえる。
- 足す案（任意）: y = 200 の高さに空気の粒 14 個（`circle` r 3、`gray`）。粒 i の x = `90 + 14i + 4·sin(2π(i/3.5 − 4t))`（縦波の密と疎）。
- 部品: rect・line・ellipse・circle・text
- 静止図との整合: t = 0 で弧は静止図と同じ x 110・150・190・230。文字の例外なし。
- restT 0、周期 4000、つながる（8 回振動・弧は 160px 進んで 1 本分ずれる）。
- テスト: t = 0 の弧の x、各 t で弧の x が 110〜270。

#### so-string-phone（sound-2-c2）B
- 動き: 糸（静止図の (74,130)–(246,130)）を 17 点の折れ線にし、`y = 130 + 3·u(t)·sin(2π(3·(x − 74)/172 − 6t))`。振動が左の紙コップから右へ伝わって見える。両はしは y = 130 に固定（はしでは振幅 0 になるよう `sin(π(x − 74)/172)` を掛ける）。
- 部品: polygon・line・text
- 静止図との整合: t = 0 で u = 0 なので静止図と同じ直線。
- restT 0、周期 4000、つながる。

#### so-light-vs-sound（sound-2-c3）A
- 動き: 0〜0.1 で花火（静止図の `circle` (60,56)）の半径が 0 → 26 に開き、まわりに火花の線 8 本。光は一瞬で届く: 0.05〜0.15 だけ人の頭（(272,160) の丸）を `yellow` にし、「見えた！」を (226,150) に出す。音: 青い弧（`line` 3 点、幅 2）が花火から人へ進む。位置 = `along([[86,70],[258,160]], stage(t, 0.1, 0.8))`。0.8 以降は「聞こえた！」を (226,186) に出す。時間の文字「光ってから X.X 秒」を (110,160) に（X = `2.0·stage(t, 0.1, 0.8)`。sound-2-c4 の 2.0 秒と同じ）。
- 部品: line・circle・polygon・arrow・text
- 静止図との整合: 地面・人・距離の矢印・文字は静止図のまま。0.99 で花火は開いたまま、音は人に届いている。
- restT 0.99、周期 4000。

## 10. 判断の記録

- 生物は写真の計画（A 48 枚）を優先し、写真に替えないカードだけから選んだ。そのため植物 0 本・動物 1 本と少ない。細胞分裂・受精の動きは、写真に替えない life-1-c2・life-2-c2・life-3-c3 で入れた。
- 1 カード 1 kind にし、kind は全単元で一意・単元の接頭辞付き（光の 23 種は接頭辞なしのまま）。
- 光の `BUILD` は書きかえず、登録口（`register`）を足す形にした。光のテスト（`KINDS` が 23 個）はそのまま通る。
- 静止図の形をつくる関数は anim 側に写し、静止図の文字の整合テストでずれを見つける。共通の部品ファイルへの移動は、content の並行作業が落ち着いてからにする。
- 乱数を使わず、振動・回転は整数回にして 1 周がつながるようにした。一方向の動きは「進む → 止まって見せる → 始めにもどる」。
- 天体の 1 周（自転・公転・月・季節）は周期 8000 ms にした（4 秒では速すぎて季節や月の形が追えない）。
- 箱の位置が力の大きさで決まるように見える動き（2 力のつり合い）や、根拠のない数値（化学変化で出ていく二酸化炭素の質量）は避けるか「例」と書いた。ch-open-container の 80.0 → 79.6 g は説明のための例の値。
- 本数の目安（40〜70 本）に合わせ、B は「動くと分かりやすくなる」ものにしぼった（音の波形の読み方、溶解度のグラフの読み、器具の使い方などは静止図のまま）。
