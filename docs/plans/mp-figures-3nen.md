### 実装の前に決めること（動く図の使い回し）

今のテスト（`tests/content-all.test.js`）には次の 2 つの決まりがあり、`anim: '<既存の kind>'` を書くだけでは通らない。

1. 「1 kind ＝ 1 カード」（kind が全単元で重ならない・登録した kind はちょうど 1 枚が使う）。
2. 静止図の `text`・`label` が `frame(kind, restT(kind))` に同じ `text`・`x`・`y` で入っている。ミニプリントのカードの静止図は元のカードとちがう（下の「動く図（使い回し）」の表の「静止図」の欄。12 枚とも文字が 1〜8 個合わない）。

おすすめ: **動きの関数はそのまま使い、別名で登録する**（例 `['mo-slope-split-mp', moSlopeSplit, { restT: SPLIT_REST }]`）。描く式を新しく書かないので「使い回し」に数えた。テストの決まりは変えずにすむ。あわせて、ミニプリントのカードの静止図を元のカードの静止図と同じにする（元のカードの `figure` を関数に出して両方から呼ぶ）。静止図からなくなる文字（式・数値など）は、カードの文にすでに書いてあることを確かめた。
別の案: テストの 1 を「`-mp` のカードは、静止図が元のカードと deepEqual なら同じ kind を使ってよい」にゆるめる。どちらにするかは Claude Code 本体が決める。

## 判断の記録

- motion は実物より「動き・力の向き・作図の手順」が本質なので、写真の新規は 0 にした。記録タイマー（motion-mp5-c2）は写真（motion-2-c3）の使い回しもできるが、anim-plan 9 章の保留（「一定の時間ごとに点を打つ」）を生かして動く図にした。
- 元のカードと同じ内容のものは使い回し（動く図 12・写真 10）。ただし内容に新しい点があるもの（浮力が深さで変わらない motion-mp1-c2、定滑車との比べ motion-mp8-c1、慣性の向きが逆の motion-mp6-c3、OH- が陽極へ動く ion-mp7-c2、太陽の方向の星座を見る space-mp3-c3）は新しい kind にした。描く式は元の kind から写せるので、作る手間は小さい。
- life-1-c1 の写真（分裂の顕微鏡写真）はあるが、heredity-mp1-c1 は順番がテーマなので、anim-plan 9 章の保留（A）にある「体細胞分裂の順序」の動く図にした。同じく heredity-mp3-c1 は保留の「花粉管がのびて受精」を動く図にした。
- 日食・月食（space-mp10-c2）は写真 space-3-c3 があるが、カードと問題が並び方を聞くので、並びが分かる動く図にした。
- space-mp1-c3 の写真（space-4-c1）にはコロナが写っていない。コロナは文字で補う（1 枚の写真に黒点とコロナを同時に写すのは実物として不自然なので、新しく作らない）。
- 指標生物（nature-mp3-c1）は、既存の nature-3-c1 が作り直しで 3 種（サワガニ・カワゲラ・ヒラタカゲロウ）になり、カードの 8 種と合わないので新規にした。
