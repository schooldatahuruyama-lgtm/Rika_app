# ライブクイズの準備（先生向け）

ライブクイズは、先生の Google アカウントで作る **Firebase Realtime Database**（無料枠）を使って、先生の画面と生徒の端末をつなぎます。最初に 1 回だけ、次の準備をします（10 分ほど）。

> 画面の名前は 2026 年の Firebase コンソールの日本語表示に合わせています。名前や場所が変わっていたら、近い名前のボタン・メニューを探してください。

## 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com/ を開き、Google アカウントでログインします。
2. 「プロジェクトを追加」（または「プロジェクトを作成」）を押します。
3. プロジェクトの名前を入れます（例: `rika-quest`）。
4. Google アナリティクスは「無効」でかまいません。
5. 「プロジェクトを作成」を押し、できあがるまで待ちます。

## 2. Realtime Database を作る

1. 左のメニューの「構築」→「Realtime Database」を開きます。
2. 「データベースを作成」を押します。
3. 場所は「asia-southeast1（シンガポール）」か、近い所を選びます。
4. セキュリティルールは「ロックモードで開始」を選び、「有効にする」を押します。

## 3. 規則（ルール）を貼る

1. Realtime Database の「ルール」タブを開きます。
2. 入っている文をすべて消し、このリポジトリの `docs/live/firebase-rules.json` の中身をそのまま貼ります。
3. 「公開」を押します。

この規則で、`rooms/<部屋コード>` 以外への書きこみと、形の崩れたデータ（名前が長すぎる参加者など）を拒みます。

## 4. データベースの URL を控える

1. 「データ」タブを開きます。
2. 上に出ている URL をコピーします。次のどちらかの形です。
   - `https://（プロジェクト名）-default-rtdb.（地域）.firebasedatabase.app`
   - `https://（プロジェクト名）-default-rtdb.firebaseio.com`

## 5. 理科クエストに URL を貼る

1. 理科クエストの先生画面 →「ライブクイズ」を開きます。
2. 「データベースの URL」に、4 でコピーした URL を貼って保存します。

URL はその端末だけに保存されます（リポジトリや生徒の端末には入りません）。生徒は部屋コードだけで参加します。

## 注意

- **無料枠**（同時接続 100、転送量 10 GB/月）で、1 クラスの授業には十分です。
- **部屋コードを知っている人は誰でも書きこめます**。部屋コードは学校の外に広めないでください。
- 送るのはニックネームと答えだけです。本名などの個人情報は入れないでください。
- 授業が終わったら、先生画面の「終了」で部屋を消してください（消し忘れた部屋も 24 時間たつと古い部屋として扱います）。
- ライブクイズはインターネットにつながっているときだけ使えます。
