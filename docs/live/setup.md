# ライブクイズの準備（先生向け）

ライブクイズは **Firebase Realtime Database**（無料枠）を使って、先生の画面と生徒の端末をつなぎます。

> **2026-11-11 から、データベースの URL はアプリに組みこみ済みです**（`js/config.js` の `live.dbUrl`）。先生も生徒も、URL を入れずにそのまま使えます。このページの手順は、**自分で別のデータベースを準備するときだけ**必要です（最後に、先生画面の「くわしい設定」に URL を貼ります）。組みこみの URL は公開リポジトリに載りますが、規則（`docs/live/firebase-rules.json`）で `rooms/` 以外への読み書きと形の崩れたデータは拒みます。

自分で準備するときは、最初に 1 回だけ次の手順を行います（10 分ほど）。

> 画面の名前は 2026 年の Firebase コンソールの日本語表示に合わせています。名前や場所が変わっていたら、近い名前のボタン・メニューを探してください。

## 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com/ を開き、Google アカウントでログインします。
2. 「プロジェクトを追加」（または「プロジェクトを作成」）を押します。
3. プロジェクトの名前を入れます（例: `rika-quest`）。
4. Google アナリティクスは「無効」でかまいません。
5. 「プロジェクトを作成」を押し、できあがるまで待ちます。

## 2. Realtime Database を作る

1. 左のメニューの「構築」→「Realtime Database」を開きます。
2. 「データベースを作成」を押します。
3. 場所は「asia-southeast1（シンガポール）」か、近い所を選びます。
4. セキュリティルールは「ロックモードで開始」を選び、「有効にする」を押します。

## 3. 規則（ルール）を貼る

1. Realtime Database の「ルール」タブを開きます。
2. 入っている文をすべて消し、このリポジトリの `docs/live/firebase-rules.json` の中身をそのまま貼ります。
3. 「公開」を押します。

この規則で、`rooms/<部屋コード>` 以外への書きこみと、形の崩れたデータ（名前が長すぎる参加者など）を拒みます。

## 4. データベースの URL を控える

1. 「データ」タブを開きます。
2. 上に出ている URL をコピーします。次のどちらかの形です。
   - `https://（プロジェクト名）-default-rtdb.（地域）.firebasedatabase.app`
   - `https://（プロジェクト名）-default-rtdb.firebaseio.com`

## 5. 理科クエストに URL を貼る

1. 理科クエストの先生画面 →「ライブクイズを始める」を開きます。
2. 「くわしい設定（別のデータベースを使う）」を開き、4 でコピーした URL を貼って保存します。「消す（組みこみに戻す）」で組みこみの URL に戻ります。

URL はその端末だけに保存されます。生徒の端末は組みこみの URL を使うので、別のデータベースを使うときは、生徒の参加画面の「くわしい設定: データベースの URL を変える」にも同じ URL を入れてもらいます。

## 6. 生徒の参加のしかた（QR コード）

- 部屋を作ると、ロビーに **参加用の QR コード** と部屋コードが大きく出ます。スクリーンに映してください。
- 生徒は、タブレットの **カメラアプリ**（iPad の「カメラ」、Android の「カメラ」や Google レンズ、Chromebook の「カメラ」アプリの QR 読み取りなど）で QR コードを読み、出てきたリンクを開きます。理科クエストが開き、部屋コードが入った参加画面になるので「参加する」を押します（プロフィールがなければ、作ったあとに参加画面になります）。
- アプリの中の「QR コードを読む」は、カメラと QR の読み取りが使える端末（Android の Chrome など）だけに出ます。使えない端末では、カメラアプリで読むか、部屋コードを入れてください。
- 途中から入る生徒のために、出題中・答え合わせ中の画面の右上にも小さく参加コードが出ます。

## 注意

- **無料枠**（同時接続 100、転送量 10 GB/月）で、1 クラスの授業には十分です。
- **部屋コードを知っている人は誰でも書きこめます**。部屋コードは学校の外に広めないでください。
- 送るのはニックネームと答えだけです。本名などの個人情報は入れないでください。
- 授業が終わったら、先生画面の「終了」で部屋を消してください（消し忘れた部屋も 24 時間たつと古い部屋として扱います）。
- ライブクイズはインターネットにつながっているときだけ使えます。
