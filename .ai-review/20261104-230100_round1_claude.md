# Claude レビュー結果（round 1: 動く図の化学・生物）

## 概要
対象は未コミットの `js/anim-chem.js`（12 本）・`js/anim-bio.js`（6 本）・`tests/anim-chem.test.js`・`tests/anim-bio.test.js`、それと content 9 ファイルの `anim:` 行 18 本。`npm test` は 473 件すべて成功した。別に Node で各 kind を t = 0〜1 の 2000 点で調べた。NaN・無限大は出ず、座標はすべて 0〜320・0〜240 に収まり、1 フレームの item は最大 51 個だった。乱数は使っていない。化学・生物として明らかな誤り（High）はない。原子・イオン・染色体の数、極と電子の向き、反射の経路、炭素の循環も正しい。写真に替える予定（image-plan の A）のカードに `anim` は付いていない（18 枚とも「簡略図のまま」）。テストは計画 3-5 と各 kind の「テスト」を満たす。指摘は次の 2 種類で、動いているときの粒子モデルの見え方と、止まった絵（restT）で静止図の情報が欠けることにかかわる。動きを減らす設定では静止図の代わりに restT の絵だけが出る（`js/ui-screens.js:849-851`・`js/anim.js:665`）。

## Claude Code の対応

| # | 分類 | 対応 |
|---|---|---|
| 1 | 対応する | st-particles の液体の粒の振れ幅を間隔の半分未満にする（重ならない）。化学の担当。 |
| 2 | 対応する | bo-reflex の「あとで熱いと感じる」を 1 周の 0.3 以上見せる（信号が脳に着く時刻を早める、または止まって見せる時間を伸ばす）。生物の担当。 |
| 3 | 対応する | io-neutralize の止まった絵（restT）に反応前のイオンも残す（restT を反応の途中にするか、左側に静止図のイオンを残す）。化学の担当。 |
| 4 | 対応する | he-meiosis-fertilize の止まった絵で親の細胞の染色体 4 本（紫）と精子・卵の色を静止図どおりにする。生物の担当。 |
| 5 | 対応する | 気体の矢印を箱の中に収める。化学の担当。 |
| 6 | 対応する | 試験管の水面の初期値を丸い底の形に合わせ、t = 0 で満水にする。化学の担当。 |
| 7 | 対応する | ch-water-formation の restT を描き終わり（色つきの水分子が出る位置）にする。化学の担当。 |
| 8 | 対応する | na-balance の位相をそろえ、restT の絵がつり合いの状態（① の前）になるようにする。生物の担当。 |
| 9 | 対応する | io-daniell でイオンが「消える・わく」ように見えないよう、Zn2+ は板から出て水溶液へ、Cu2+ は水溶液から板へ着いて銅になる、を複数の位相で切れ目なく見せる。化学の担当。 |
