# Claude レビュー結果（round 1）

## 概要
`content/solution.js`・`content/state-change.js`・`content/plants.js` と `docs/reports/content/` の 3 単元を読み取り専用で確認した（`node --test tests/content-all.test.js` は 65 件すべて成功）。データの形、fill の語群、figure-choice の region、数値（溶解度・融点・沸点）、植物の分類はおおむね正しく、教科書名や生徒を責める表現もない。ただし前のサイクルの指摘 3 と同じ種類の問題（drag の許容 16px の中に、意味の上で誤答になる位置が入る）が `sol-4-p3` にある。ほかに、概念 id の接頭辞の決まりが守られていない。

確認した点（問題なし）:
- `sol-3-p4`（飽和になる温度に印）: 許容 16px は 4℃ ぶん（36〜44℃）で、意味の上で誤答になる位置は入らない。
- `plants-1-p3`（花粉を柱頭へ）・`plants-1-r1`（印を胚珠へ）: 許容 16px より 花粉 r10 ＋ 柱頭 r7・印 r10 ＋ 胚珠 r14 のほうが大きく、許容内ではいつも目標に重なる。やく（35px）・子房のかべ（72px）は入らない。
- fill の答えはすべて語群にあり、figure-choice の答えはすべて図の region にある。region の r はすべて 22 以上で、となりどうし重ならない。部品と文字は 320×240 の中に収まる。
- 数値: 硝酸カリウムの溶解度（20℃ 32 g・40℃ 64 g・60℃ 110 g）、塩化ナトリウム約 36 g、再結晶の 110 − 32 ＝ 78 g、濃度の計算、融点・沸点の表（水 0/100、エタノール −115/78、酸素 −218/−183、鉄 1535/2750）、氷の体積 約 1.1 倍は正しい。
- 植物: 花のつくりの順、子房 → 果実・胚珠 → 種子、マツの雌花・雄花の位置、被子・裸子・単子葉・双子葉・合弁花・離弁花・シダ・コケの分類と例は正しい。蒸留の装置には栓がある。
- 教科書名・出版社名は 3 ファイルと内容一覧のどこにもない。

## Claude Code の対応

| # | 分類 | 対応 |
|---|---|---|
| 1 | 対応する | sol-4-p3 を、溶解度曲線で「20 ℃ でとけている質量（32 g）」の位置に印を上下に動かす drag に差しかえた（110 g・78 g の位置は 69px 以上はなれる）。ろ過の配置の問題は sol-4-p2（figure-choice）で扱っているので内容の欠けはない。 |
| 2 | 対応する | 1 年の 6 単元すべての概念 id に接頭辞を付けた（sound `so-`、force `fo-`、substance `su-`、solution `sol-`、state-change `sc-`、plants `pl-`）。確認問題の id・問題の concept・ステージの concepts・basic・内容一覧もそろえた。光（light）は公開済みで記録があるので変えない。 |
| 3 | 対応しない | state-4-p3 の温度計: 許容の上端がゴム栓の下面に当たる位置だが、「枝の高さ」から 16px 以内であり、誤答として教えたい位置（球が液の近く）は十分はなれている。図の作り直しはしない。 |
| 4 | 対応する | 混合物のグラフの折れ目を 78 ℃ より上（約 80 ℃）に上げた（state-change.js の mix の曲線と state-3-p2 の図）。 |
| 5 | 対応する | sol-3-p2・sol-3-r1 は答えの数値を図に書かない `graphItems(false)` にし、10 g ごとのうすい横線を足して、許容を ±4 g にした。 |
| 6 | 対応する | sol-3-p3 の「塩化ナトリウム」の文字を右上（300, 150、右寄せ）へ移した。 |

修正後: `npm test` を実行し、round 2 を依頼。
