# Codex レビュー結果（round 1）

## 概要

未コミット差分と新規ファイルを指示書と照合しました。バッジの取得・表示・先生画面への追加は概ね整合していますが、不正データの扱いに1件の指摘があります。

## 指摘事項

| # | 重要度 | ファイル:行 | 内容 | 修正案 |
|---|---|---|---|---|
| 1 | Medium | `js/badges.js:152–156` | **取得日時の型が不正でも未読扱いになります。** 例えば `{ at: 5, seen: false }` は `{ at: null, seen: false }` となり、`unseen()` に含まれて次の結果画面で「新しいバッジ！」として表示されます。指示書94行目の「`at` が文字列でない項目は取得済み・`seen: true` 扱い」と不一致です。 | `at` または `seen` の型が不正なら、取得済み状態を維持して `seen: true` を返してください。`at` だけ不正で `seen: false` の場合もテストに追加してください。 |

## Claude Code の対応


- #1 Medium（entry の at/seen が崩れたとき未読扱い）: **対応した**。`js/badges.js` の `entry` を「at か seen のどちらかでも形が崩れていれば seen: true」に変更。`tests/badges.test.js` に at だけ不正で seen:false のケースと seen だけ不正のケースを追加（npm test 553 件成功）。
