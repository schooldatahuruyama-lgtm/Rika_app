# Claude レビュー結果（Task 14 / round 1）

## 仕様適合
- ✅ 適合: Step 1〜2 の要求はすべて差分にある。
  - `sw.js`: VERSION / CACHE_NAME、install で PRECACHE を addAll → `skipWaiting()`（sw.js:41-48）、activate で `rika-quest-` で始まる他のキャッシュを削除 → `clients.claim()` → 全ウィンドウに `offline-ready`（sw.js:50-59）、fetch は navigate なら `index.html`、それ以外は同一オリジンでキャッシュ優先・ネットで取れたらキャッシュ（sw.js:71-100）。
  - 登録: http/https かつ `'serviceWorker' in navigator` のときだけ `register('sw.js')`。失敗すれば `failed`（js/app.js:487-526）。`offline-ready` を受けて `app.offline` と `rika-quest:offline` に try/catch つきで書く（js/app.js:460-484）。
  - 設定画面: `app.offline` を優先し、なければ localStorage を try/catch で読んで 4 種類の文言のどれかを出す（js/ui-screens.js:548-596）。`caches` は画面側で使っていない。
  - README に更新手順（VERSION を上げる → 次のオンライン時に入れ替わる → 記録は残る）がある（README.md:45-49）。
  - コントローラが認めた逸脱 3 件（manifest リンクを app.js が http(s) のときだけ足す、`status` 問い合わせへの返事、tests/offline.test.js）は認められた範囲に収まっている。
  - 小さな違い: VERSION が指示の `'2026-11-03-1'` ではなく `'2026-11-04-1'`（sw.js:7）。形は同じで動作への影響はない。PRECACHE の並びを index.html の読み込み順にしたのも問題ない。
- ⚠️ 差分だけでは確認できない: Step 3 のブラウザ確認（オフラインで `/` と `/index.html` を開き直す、解答・XP の記録、VERSION を上げたときの入れ替わり、file:// でコンソールエラー 0 件）は報告の主張のみ。オフラインは DevTools の Offline ではなくサーバー停止で再現している（同じことを確かめられる方法なので妥当）。file:// は headless Edge で確認とあるが、スクリプトは差分に含まれていない。

## 良い点
- fetch ハンドラの最初で GET 以外と別オリジンを素通しにしている（sw.js:72-73）。POST や外部への要求には触らない。
- ネットで取ったものをキャッシュに入れる条件が `response.ok && response.type === 'basic'`（sw.js:92）。opaque やエラーの応答は入らない。`cache.put` の失敗（206 など）は `.catch` で吸収している。
- install で `new Request(url, { cache: 'reload' })`（sw.js:45）としているので、VERSION を上げたときにブラウザの HTTP キャッシュの古いファイルが新しいキャッシュに入らない。指示にはないが、更新を正しく動かすために必要な配慮。
- activate の削除が `rika-quest-` で始まるキャッシュに限られていて（sw.js:53-55）、同じオリジンの他のキャッシュを消さない。
- 画面の message の受け取りを `register` より前に付けている（js/app.js:508-511）。初回の activate の知らせを取りこぼさない。
- localStorage の読み書きがどちらも try/catch つきで、壊れた JSON も「印なし」として扱う（js/app.js:460-476, ui-screens.js:562-567）。
- file:// では manifest のリンクも SW の登録も行わないので、CORS エラーと登録エラーの両方を避けられる（js/app.js:495-505）。
- 設定画面は `#offline-status` の箱だけを描き直すので、スクロール位置やお知らせが残る。画面を離れた後に届いた知らせで受け取りをやめる。
- tests/offline.test.js が index.html の `<script>`/`<link>` と PRECACHE の食い違い（JS は並びまで）、ファイルの実在、重複を確かめている。ファイルを足して PRECACHE を更新し忘れたら `npm test` で見つかる。
