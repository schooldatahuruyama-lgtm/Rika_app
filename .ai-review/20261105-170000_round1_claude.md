# Claude レビュー結果（round 1: 先生画面の初期パスコード）

## 概要
対象は初期パスコード（`js/config.js` の salt/hash）、`js/teacher-gate.js`、`js/ui-teacher.js`、`tools/teacher-passcode.js`、テスト、README、`sw.js`。`npm test` は 540 件すべて成功。生徒がパスコードを決める・変える経路は画面上に残っていない（決めるフォームは削除済み。変えられるのは開いた先生画面の中だけ）。保存データがないときは config の初期パスコードで照合し、「すべて削除」は上書きと失敗回数を消して初期に戻すだけ。ハッシュは `Math.imul` と UTF-8 バイト列だけで決まるので Node とブラウザで同じ結果になり、salt/hash が config にある点は許容範囲。README・テスト・報告には本物のパスコードの値は書かれていない（確認のため、テストで使う値と数字の候補を config の hash に照合し、どれも一致しないことを確かめた）。High と Medium はなし。
