# Claude レビュー結果（Task 9 / round 1）

## 仕様適合
- ✅ 適合（指示書の必須事項に抜け・取り違えはない）:
  - `sceneSvg` は `viewBox="0 0 w h"` を出し、各 item を `<g data-item-id data-item-type>` で包む（js/figures.js:238-243）。
  - opts の `highlightRegion` / `draggableId` / `extraRays` は実装済み。`is-selected` は region にだけ付く（js/figures.js:235）。
  - 13 種類の type がすべて `DRAW` にある（js/figures.js:94-219）。region の r は 22 未満なら 22 に補正される（js/figures.js:30, 184）。
  - `escapeText` は `& < > " '` を処理し、label・text・メッセージはすべてこれを通る。
  - `mascot.NAME`（'ピカ'）は 1 か所で、リポジトリ内の他の場所に重複はない。`svg(size)` と `celebrateMarkup(message)` もある。
  - IIFE 形式、DOM なし、外部依存なし、`type="module"` なしで、赤は使っていない。
  - 鏡の裏側は `geometry.normalOf` をそのまま使っているので、判定と図の向きがずれない（js/figures.js:96-100）。
- 余分: `ITEM_TYPES` の export（js/figures.js:259）。依頼にはないが小さく、害はない。
- ⚠️ 差分だけでは確認できない:
  - ブラウザでの見た目。実装者の報告は、ヘッドレス Edge のスクリーンショットで目視したとしている。
  - `index.html` の読み込み順（geometry.js → figures.js → mascot.js）。`index.html` は Task 12 以降で作られる。呼ぶ時点で読み込み済みなら動く作りにはなっている。
  - 報告にあるテスト出力（93 件成功）。生の出力は添付されておらず、この査読では再実行していない。

## 良い点
- `geometry()` / `figures()` を呼ぶ時点で取り出す方式なので、Node でもブラウザでも読み込み順に依存しにくい。
- `attrs()` が属性値をすべてエスケープし、`num()` が NaN などを 0 に、小数を 2 けたに丸める。label だけでなく属性（`data-item-id` など）も安全で、数値の揺れもテストしやすい。
- 長さ 0 の鏡（0 除算）、未知の type や null の item、`scene` が null、`extraRays` に null が混じる場合を、落ちずに処理している。
- `ray` と `extraRays` が `rayLine` を共有しており、重複がない。
- テストが `is-selected` / `is-draggable` を正規表現で「その id の g に付くこと」まで見ている。エスケープ後の文字列と、元の `a<b` が出力に残らないことの両方を検証している。
