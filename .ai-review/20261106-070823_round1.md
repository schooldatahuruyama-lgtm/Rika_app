## Claude Code の対応
- #1 High（生成中の編集で生成済みステージが消える）: **対応した**。生成中はその下書きの編集・作り直し・貼り付け・削除を disabled にし、段階ごとの保存後に画面の下書きを最新に置きかえる（js/ui-author.js）。
- #2 High（空の選択肢で正解がずれる）: **対応した**。空の選択肢・枠は除かず errors に出す（番号は保つ）。
- #3 High（描画できない空らん id）: **対応した**。blanks の id を b1… に付け直し、本文の [id] も同じ順で置きかえる。
- #4 Medium（壊れた下書きの取り込み）: **対応した**。isDraft で plan・stages の中身まで検査。assembleUnit は欠けた項目で例外を出さず errors に書く。
- #5 Medium（用語問題の検査）: **対応した**。assembleUnit で各ステージに term:true の fill があることを検査。
- ほかに controller のブラウザ確認で、枠選び（boxesScene）の文字が左上の丸と重なる点と、「すべて削除」で API キーが残る点を直した（指示書 .ai-tasks/20261106-080000_教材作成_修正1.md）。tests 586 件成功。
